# 粘贴剪贴板图片发送

- 状态：已实现（待手测）
- 背景：截图后常想直接发给对面；现网 Ctrl+V 只认文件路径，剪贴板里的图片字节流会落到输入框或无效。
- 目标：选中对端后，Ctrl+V 若剪贴板含图片（无本地文件路径优先时），保存为临时 PNG 并按拖放规则入队发送。
- 非目标：
  - 粘贴多帧/动图优化
  - 自定义截图命名规则 UI
  - 改纯文本粘贴行为

## 用户故事

作为使用者，我截完图 Ctrl+V 就能发出去，不必先存盘再拖。

## 行为

1. 焦点在输入框或聊天区 Ctrl+V：若剪贴板已有本地文件 URL → 仍按原文件粘贴逻辑（优先于图片）。
2. 否则若有图片数据：写入临时目录 `…/landrop-paste/screenshot-时间戳.png`，入队发送；吞掉默认粘贴。
3. 未选对端：提示与拖放一致。
4. 发送中：走自动入队。
5. 无图片且无文件：不拦截，输入框正常粘贴文字。

## 验收标准

- [ ] I1：Win+Shift+S 截图后在输入框 Ctrl+V，对端收到 PNG。
- [ ] I2：资源管理器复制文件后 Ctrl+V 仍发文件，不误发图片。
- [ ] I3：仅文字剪贴板时 Ctrl+V 仍插入输入框。
- [ ] I4：未选对端时粘贴图片有提示。
