# 顶栏工具图标视觉尺寸一致

- 状态：已实现（待手测）
- 背景：顶栏下载目录 / 设置 / 置顶 / 最小化 / 最大化 / 关闭一组图标，有的 20px SVG、有的 16px 自绘，线宽也不齐，看起来一大一小。
- 目标：同一行图标占用相近视觉框、线重接近，扫描时不别扭。
- 非目标：改图标语义或配色体系（文件夹可仍用橙色强调）；不重做输入区工具栏图标。

## 用户故事

作为使用者，我希望顶栏那一排小图标大小和粗细看起来是一套的。

## 行为

1. 顶栏上述 6 个按钮统一 **约 18×18** 图标逻辑尺寸，按钮热区仍约 40×32。
2. 自绘窗口控制与置顶图标线宽与 Lucide 系 SVG（约 stroke 2 / 24 档）视觉接近。
3. 最小化横线等「过轻」图形略加长，避免在同行里显得更小。
