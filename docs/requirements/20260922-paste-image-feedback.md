# 粘贴截图有发送确认反馈

- 状态：已实现（待手测）
- 背景：Ctrl+V 粘贴剪贴板图片会入队发送，但聊天区可能一时看不出「已经贴出去了」，像没反应。
- 目标：成功把截图入队后立刻给可见反馈（系统条或短提示），并带上临时文件名。
- 非目标：改粘贴优先级；改临时目录策略。

## 用户故事

作为使用者，我截图后 Ctrl+V，希望马上知道已经开始发给对方。

## 行为

1. 剪贴板图片成功落临时 PNG 并入队后：当前会话插入系统条，如「已粘贴截图，开始发送」。
2. 可选：短暂 tooltip「已粘贴截图」。
3. 保存失败：不插假成功条；尽量不吞事件或给失败提示。
4. 未选对端、文件优先粘贴等路径不变。

## 验收标准

- [x] P1：截图 Ctrl+V 后聊天区出现「已粘贴截图…」类系统条且文件开始发送（实现已对齐，待手测）
- [x] P2：复制文件路径后 Ctrl+V 仍发文件，不出现截图系统条（实现已对齐，待手测）
