# 文字消息乐观发送

- 状态：已实现（待手测）
- 背景：点 Enter / 发送后，气泡要等 HTTP 成功才出现，输入框也不先清空；网络稍慢时连按会重复发出同一句。文件发送已有进行中卡，文字侧不一致。
- 目标：发出文字后立刻出右侧气泡并清空输入；成功再标「已送达」时延；失败去掉该气泡并走既有失败提示。
- 非目标：
  - 文字编辑/撤回协议
  - 改文件上传乐观逻辑
  - 发送中可取消单条文字

## 用户故事

作为使用者，我希望回车后马上看到自己发的话、输入框清空，能继续打下一句，不必干等对端回包。

## 行为

1. 点发送或 Enter：若有选中对端且正文非空 → 立刻在该会话追加发出文字气泡（暂无「已送达」）、清空输入框，并发起请求。
2. 请求成功：该条补上绿色「已送达 - Nms」（与现网一致）。
3. 请求失败：移除该条乐观气泡，并按现有 `noteFail` 插入失败提示（含重试若适用）。
4. 空内容、未选对端：仍不发送。
5. 离线轻提示等前置逻辑保持不变。

## 验收标准

- [x] O1：回车后气泡立刻出现且输入框清空，不必等送达勾（实现已对齐，待手测）
- [x] O2：成功后出现「已送达 - Nms」（实现已对齐，待手测）
- [x] O3：对端不可达时乐观气泡消失并有失败提示；不残留「假成功」气泡（实现已对齐，待手测）
- [x] O4：慢网络下连按不会因输入框未清空而重复同一句（实现已对齐，待手测）
