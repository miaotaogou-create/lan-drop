# 托盘快捷开关通知声

- 状态：已实现（待手测）
- 背景：关通知声要进设置；开会时不够快。
- 目标：托盘菜单增加可勾选「通知声」，热切并写入 settings.json。
- 非目标：音量滑条；按事件分铃。

## 用户故事

作为使用者，我希望右键托盘就能立刻静音/开声。

## 行为

1. 托盘菜单在「打开下载目录」附近增加勾选项「通知声」。
2. 勾选状态与 `soundNotification` 一致；切换后立即生效并 `save()`。
3. 打开设置对话框时开关与托盘勾选一致（读当前 settings）。

## 验收标准

- [ ] M1：托盘可勾选/取消「通知声」，收消息时静音与否立刻变化。
- [ ] M2：重启后勾选状态保持。
- [ ] M3：设置页同一开关与托盘同步。
