# 文件卡圆角位图与现代进度条

- 状态：已实现（待手测）
- 背景：文字气泡已位图圆角，文件卡仍是 HTML 直角 table + 拼条进度，传文件时最显「旧」。
- 目标：文件卡改为圆角白卡位图，含圆角进度条与圆角角标；完成态点卡面可打开；底部操作链保留。
- 非目标：改传输协议；重做文件 Tab 布局；聊天内搜索。

## 用户故事

作为使用者，我希望文件消息看起来和文字气泡一样现代，进度条也好认。

## 行为

1. 收/发文件卡：圆角白底、浅边，角标圆角，文件名与大小清晰。
2. 传输中：圆角进度轨 + 蓝色填充，状态文案随进度。
3. 完成后：完成态提示；有本地路径时点卡面打开文件。
4. 「打开所在目录 / 复制路径」仍在卡下可点；缩略图（若有）仍可点。
