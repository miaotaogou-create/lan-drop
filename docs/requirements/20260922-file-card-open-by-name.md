# 文件卡点文件名即可打开

- 状态：已实现（待手测）
- 背景：传输完成后底部有「打开文件」小链，非图片卡要点到很小区域；缩略图已可点，文件名区却不能。
- 目标：传输完成且本地路径存在时，点徽章旁的文件名/大小即可打开文件（与「打开文件」同链路）。
- 非目标：传输中可点打开；改底部三个动作文案；双击空白气泡区复杂命中。

## 用户故事

作为使用者，我收到或发完文件后，希望点一下文件名就能打开，不必找底部小字。

## 行为

1. 已完成且有本地路径的文件卡：文件名与大小可点，打开该文件。
2. 图片缩略图仍可点打开（既有）。
3. 「打开所在目录」「复制路径」仍独立可点。
4. 发送中/接收中：文件名不可点打开。
