# Composer 工具栏并入输入浮卡

- 状态：已实现（待手测）
- 背景：工具槽平贴在上、输入壳另浮一层，输入区像两块拼装；与侧栏搜索/hostPill 单卡语言不一致。
- 目标：附件/文件夹/抖动与输入框同属一张浮起白卡（上工具条、下输入区）。
- 非目标：改发送/文件夹/抖动逻辑；把发送钮挪出卡片；重做快捷键提示行。

## 用户故事

作为使用者，我希望打字区是一整块现代输入卡，而不是「灰槽 + 白框」两层。

## 行为

1. `#composerToolBar` 嵌在 `#inputShell` 顶部（不再独立于壳外）。
2. 工具条：浅灰顶条 + 底部分隔线；圆角只在卡顶，与壳一体。
3. 输入区仍在壳内；整卡保留一层 `applyFloatingShadow`。
4. 聚焦时整卡蓝边（现有 inputShell focused 行为不变）。
