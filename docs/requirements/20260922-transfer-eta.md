# 传输进度粗略剩余时间

- 状态：已实现（待手测）
- 背景：已有百分比与速率，大文件仍难判断还要等多久。
- 目标：速率稳定时进度文案附带粗略 ETA（如「约 3 分」「约 40 秒」）。
- 非目标：精确倒计时 UI；速率过低时硬猜。

## 用户故事

作为使用者，我传/收大文件时希望大概知道还要几分钟。

## 行为

1. 发送/接收进度在算得出速率且剩余字节明确时：附加「约 X 秒」或「约 X 分」。
2. 速率过低（如 &lt; 8KB/s）或剩余未知：不显示 ETA。
3. 与现有百分比、速率、排队文案可并存。

## 验收标准

- [ ] E1：传较大文件且速率可见时，进度出现「约 …」。
- [ ] E2：刚开始或极慢时可不显示 ETA。
- [ ] E3：收文件（空闲时）同样可显示 ETA。
