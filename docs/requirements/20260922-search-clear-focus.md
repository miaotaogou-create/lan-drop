# 搜索框清空与快捷聚焦

- 状态：已实现（待手测）
- 背景：搜完设备要手动全选删除；想搜时还要鼠标点搜索框。
- 目标：搜索框带清除按钮；Esc 清空；Ctrl+F 聚焦搜索。
- 非目标：搜索历史、拼音模糊。

## 用户故事

作为使用者，我筛完设备想马上清掉关键字，并希望快捷键直达搜索。

## 行为

1. 搜索框启用系统清除按钮（有字时右侧 ×）。
2. 焦点在搜索框时按 Esc：清空关键字并恢复列表。
3. 主窗口内 Ctrl+F（或 Command+F）：聚焦搜索框并选中已有文字。
4. 清空后空态与列表与现网「无搜索」一致。

## 验收标准

- [ ] E1：输入关键字后出现 ×，点 × 清空并列表恢复。
- [ ] E2：搜索框有焦点时 Esc 清空。
- [ ] E3：任意处 Ctrl+F 聚焦搜索框。
