# 设备列表在线与未读优先

- 状态：已实现（待手测）
- 背景：列表按发现顺序排列，离线节点常顶在上面，找在线或有未读的人对端费劲。
- 目标：刷新列表时排序：在线优先，同级未读多优先，再按显示名。
- 非目标：手动置顶；拖拽排序；改发现协议。

## 用户故事

作为使用者，我希望打开软件先看到在线和有新消息的设备。

## 行为

1. `refreshPeers` 填表前对对端排序：在线 > 离线；同级按未读数降序；再按 `label()` 不区分大小写。
2. 当前选中对端在刷新后尽量保持选中（现有 keep 逻辑不变）。
3. 搜索过滤仍按关键字隐藏，不改排序键以外逻辑。

## 验收标准

- [ ] S1：同时有在线与离线时，在线排在离线前。
- [ ] S2：两台在线，有未读的排在更前。
- [ ] S3：刷新后当前会话仍保持选中（若仍在列表）。
