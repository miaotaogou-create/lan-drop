# 文件 Tab 手型、搜索放大镜与缩略图圆角

- 状态：已实现
- 背景：聊天气泡 landrop 链接有手型，文件 Tab 同链仍像死文本；侧栏搜索白卡无 leading 图标，不如顶栏 hostPill 有识别感；完成态图片缩略图是直角裸图，与圆角文件卡脱节；复制反馈跟鼠标飘，不像现代白卡 toast。
- 目标：文件 Tab 悬停手型/tooltip 与聊天一致；搜索壳左侧灰放大镜；图片缩略图圆角浅边；miniToast 锚在输入卡上方。
- 非目标：改打开/复制逻辑；新搜索引擎；远程桌面。

## 用户故事

作为使用者，我希望在「文件」页悬停芯片也像可点；侧栏搜索一眼认出是搜索；发图缩略图好看；复制后提示固定出现、不跟鼠标跑。

## 行为

1. `m_files` 的 `highlighted` 与聊天共用悬停处理；手型与 tooltip 文案一致；离开链时恢复光标。
2. `#searchShell` 左侧有 16px 灰放大镜；聚焦蓝边、清除钮行为不变。
3. 完成态图片缩略图带圆角与浅灰描边（缓存键随样式版本失效）。
4. `showMiniToast` 优先锚在输入白卡上方居中；无输入区时落在主窗下中。

## 验收标准

- [x] F1：文件 Tab 悬停打开/目录/复制路径/重试等为手型，tooltip 与聊天一致
