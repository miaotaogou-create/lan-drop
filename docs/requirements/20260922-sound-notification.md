# 新消息与传输完成通知声

- 状态：已实现
- 背景：设置里「新消息与传输完成通知声」已可开关并入库，但收消息/收文件时不发声。
- 目标：打开开关时，收到对端文字或文件落盘后播放一次本机系统提示音；关闭则静音。
- 非目标：
  - 自定义铃声文件、音量滑条
  - 发送成功时的提示音（见 `20260922-send-complete-sound.md`）
  - 引入 Qt Multimedia 新模块

## 用户故事

作为使用者，我希望在忙别的事时，对端发来文字或文件能有一声提醒；也可在设置里关掉以免打扰。

## 行为

| 事件 | 开关开 | 开关关 |
|------|--------|--------|
| 收到普通文字 | 播一次提示音 | 不播 |
| 收到文件并落盘 | 播一次提示音 | 不播 |
| 收到抖动 | 不额外播（仍只走抖动逻辑） | — |
| 本机发出消息/文件成功 | 不播 | — |

提示音用系统默认提示（Windows `MessageBeep`，其它平台 `QApplication::beep`），不捆绑 wav。

保存设置后立即按新开关生效，无需重启。

## 验收标准

- [x] N1：开关默认开；对端发文字到本机，能听到一次提示音
- [x] N2：对端发文件到本机落盘后，能听到一次提示音
- [x] N3：设置里关掉「通知声」并保存后，再收文字/文件不再发声
- [x] N4：收到抖动时不因本功能多播一声（可有窗口抖动，无额外 beep）
