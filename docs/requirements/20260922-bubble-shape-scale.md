# 聊天气泡形状对齐参考图并放大字号

- 状态：已实现（待手测）
- 背景：对照最新参考图，文字气泡圆角偏紧、内边距与字号偏小，整体比参考图「小一号」；需仔细对齐形状并整体放大可读性。
- 目标：文字气泡外形更接近参考图（柔和圆角矩形、无尾巴）；气泡与正文字号明显更大，仍易扫读。
- 非目标：
  - 重做文件卡/代码块交互与进度条逻辑
  - 给文件卡做完整位图重绘（本轮仅同步放大字号/留白）
  - 改气泡配色体系或左右对齐规则

## 用户故事

作为使用者，我希望聊天区文字气泡一眼对得上参考图的圆角与比例，字也更大更好认。

## 行为（对照参考图）

1. 文字气泡：四角统一柔和圆角（约 16px），无尖角/尾巴；发出蓝底白字，收到白底深字 + 浅灰细边。
2. 正文字号约 **16px**（原约 14px）；内边距加大，短句气泡视觉更大。
3. 气泡内容最大宽度约 **400px**，长文仍自动换行。
4. 字母头像略放大（约 **44px**），与更大气泡比例协调。
5. 元数据行、代码块正文、文件卡标题等字号随聊天区整体上调一档，避免「气泡大了旁边字还很小」。
