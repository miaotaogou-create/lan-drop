# 输入框与搜索框聚焦描边

- 状态：已实现（待手测）
- 背景：输入壳与侧栏搜索无 focus 态，打字/搜设备时缺少「正在操作」反馈。
- 目标：聚焦时边框变主色蓝，失焦恢复浅灰。
- 非目标：改输入高度或搜索逻辑。

## 用户故事

作为使用者，我点进输入框或搜索框时，希望一眼确认焦点在哪。

## 行为

1. 聊天输入壳获得焦点：边框 `#3b82f6`（或同系主色）。
2. 失焦：恢复默认浅灰边。
3. 侧栏搜索框同样有 focus 描边。

## 验收标准

- [x] F1：点输入框出现蓝色描边（实现已对齐，待手测）

- [x] F3：搜索框聚焦同样有描边（实现已对齐，待手测）
