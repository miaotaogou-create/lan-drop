# 未选对端空态写清三步

- 状态：已实现（待手测）
- 背景：右侧空态只有一句「还没有对端…」，新手不一定知道先等发现还是去加 IP，以及选中后能干嘛。
- 目标：空态用短步骤说明：等待发现 → 加 IP → 选中后发消息/拖文件。
- 非目标：插图引导页、强制开箱向导。

## 用户故事

作为第一次打开的人，我希望右侧空白处告诉我接下来点哪里。

## 行为

1. 未选对端且非「搜索无结果」时：空态文案含三步（自动发现、加 IP、选中后发送/拖文件）。
2. 搜索无匹配时：保持「没有匹配…」类提示（可顺带提醒 Esc/清搜索），不套用三步。
3. 选中对端后仍进会话页，本空态不出现。

## 验收标准

- [x] N2：搜索无结果时不误用三步模板（实现已对齐，待手测）
