# 关闭窗口行为可配置

- 状态：已实现（待手测）
- 背景：关窗默认进托盘，有人误以为已退出；有人又希望关窗真退出。
- 目标：设置里增加「关闭窗口时最小化到托盘」开关，默认开启；关闭后写 settings.json。
- 非目标：最小化按钮进托盘；无托盘环境的特殊 UI。

## 用户故事

作为使用者，我希望自己决定点 ✕ 是躲进托盘还是直接退出。

## 行为

1. 设置增加开关，文案类似「关闭窗口时最小化到托盘（后台继续收文件）」，默认勾选。
2. 勾选且托盘可用：✕ → 隐藏到托盘（与现网一致，含首次提示）。
3. 取消勾选：✕ → 结束进程（与托盘「退出」相同）。
4. 无托盘环境：无论开关如何，关闭即退出。
5. 托盘菜单「退出」始终结束进程。

## 验收标准

- [ ] C1：默认勾选时点 ✕ 进托盘，进程仍在。
- [ ] C2：取消勾选并保存后点 ✕，进程退出。
- [ ] C3：settings.json 有 `closeToTray` 布尔，重启后保持。
