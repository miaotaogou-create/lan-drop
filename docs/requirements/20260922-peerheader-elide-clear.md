# 会话顶栏省略、清空入口与侧栏宽度约束

- 状态：已实现
- 背景：窄窗时对端名/地址与 Tab 挤叠；清空聊天只能右键；侧栏 `qBound` 参序不当，极端宽度下主区可被挤；空输入时脚注仍写「回车发送」；加 IP/置顶缺按下态。
- 目标：顶栏长名/地址省略且 tooltip 全量；顶栏一键清空（走既有危险确认）；侧栏宽钳制并保证右区最小宽；空输入脚注文案切换；加 IP/置顶有 pressed。
- 非目标：改清空语义；重做会话顶栏信息架构。

## 用户故事

作为使用者，我希望窄窗也能看清设备名（悬停看全称）；清空聊天不用找右键；拖侧栏时聊天区不会被吃光。

## 行为

1. `peerName`/`peerAddr` 按可用宽度省略（右/中），tooltip 含全名与完整地址。
2. 会话顶栏「清空」图标钮 → `clearSelectedPeerChat`（红确认不变）。
3. 侧栏宽 `qBound(220, w, 480)`；右区 `minimumWidth`≥320；持久化同钳制。
4. 有对端无字时脚注「输入消息后发送」；`#addBtn`/`#pinBtn` 有 `:pressed`。

## 验收标准

- [x] H1：最小窗+长设备名时顶栏单行省略，悬停见全名
- [x] H2：顶栏清空钮可走清空确认流
- [x] H3：侧栏拖到最宽时聊天区仍≥约 320px 可用
- [x] H4：选中对端、输入为空时脚注为「输入消息后发送」
- [x] H5：加 IP / 置顶按下有更深底色
