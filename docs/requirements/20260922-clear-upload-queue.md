# 清空发送排队

- 状态：已实现（待手测）
- 背景：「取消」会中止当前文件并清空整队；有时只想丢掉后面误拖的文件，当前大文件继续传。
- 目标：发送中且排队非空时，进度旁增加「清空排队」：只清 `m_uploadQueue`，不中断当前上传。
- 非目标：逐项删除/调序 UI；改「取消」语义。

## 用户故事

作为使用者，我传大文件时又误拖了一堆，希望只清掉排队、别打断当前这个。

## 行为

1. `m_uploading` 且 `m_uploadQueue` 非空：聊天页与文件页进度旁显示「清空排队」（与「取消」并列）。
2. 点「清空排队」：清空队列；系统条「已清空发送排队」；当前上传继续；进度文案去掉「排队还剩」。
3. 队列空或未在发送：隐藏该按钮。
4. 「取消」仍中止当前并清空排队（不变）。

## 验收标准

- [ ] Q1：发送中再入队后，可见「清空排队」。
- [ ] Q2：点后当前文件继续传完，排队文件不再发；有系统条。
- [ ] Q3：清空后按钮消失；「取消」仍可停当前。
