# 拖放/粘贴文件夹可选 zip

- 状态：已实现（待手测）
- 背景：按钮发送文件夹已可选 zip，拖到聊天/设备列表仍只发顶层，能力半闭合。
- 目标：拖放或粘贴含嵌套子目录的文件夹时，复用「打包 zip / 仅发顶层 / 取消」。
- 非目标：网页共享拖放改 zip；多文件夹各自弹多次框。

## 用户故事

作为使用者，我把工程目录拖进会话时也希望能整包 zip 发出，不必改点按钮。

## 行为

1. 拖放/粘贴 urls 中含目录且该目录有子目录：弹出与「发送文件夹」相同的三选（zip / 仅顶层 / 取消）。
2. 选 zip：对该（些）嵌套目录异步打包后入队；同批散落文件一并入队。
3. 选仅顶层：展开各目录顶层文件 + 散落文件入队（旧行为）。
4. 目录无嵌套：不弹框，直接发顶层/文件。
5. 多个嵌套目录一次询问；选 zip 则依次打包再入队。

## 验收标准

- [ ] D1：拖入含子目录的文件夹可选 zip 并成功发送。
- [ ] D2：选仅顶层行为与旧拖放一致。
- [ ] D3：无子目录的文件夹拖入不弹框。
- [ ] D4：取消不发送。
