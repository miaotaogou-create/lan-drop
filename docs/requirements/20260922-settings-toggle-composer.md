# 设置真开关、铃声收拢与 Composer 工具槽收紧

- 状态：已实现（待手测）
- 背景：设置里仍是方勾却叫 Switch；自定义铃声挂在全部开关之后，与「通知声」脱节；Composer 工具钮文案偏长，与会话分段 Tab 语言不齐。
- 目标：开关改为右对齐胶囊 Toggle；铃声嵌在通知声下方（关则灰显）；工具钮文案缩短并以 tooltip 补全，槽样式对齐分段 Tab。
- 非目标：设置/共享完整 token 抽公共库；会话顶栏再减负（下轮）。

## 用户故事

作为使用者，我希望：设置开关一眼像现代 Toggle；改铃声时就在「通知声」下面；输入区附件/文件夹按钮更紧凑好点。

## 行为

1. 设置五项开关：右对齐胶囊 Toggle（开蓝关灰），不再用方勾。
2. 「自定义铃声」整块嵌在「通知声」开关下方；通知声关闭时铃声区灰显不可操作。
3. Composer：按钮文案改为「文件 / 文件夹 / 抖动」，完整说明进 tooltip；工具槽圆角与悬停/按下态对齐分段 Tab。
4. 设置正文可滚动，细滚动条。
