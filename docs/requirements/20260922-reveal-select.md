# 打开所在目录并选中文件

- 状态：已实现（待手测）
- 背景：「打开所在目录」只打开父文件夹，文件多时还要自己找；Windows 资源管理器支持 `/select` 高亮目标。
- 目标：点「打开所在目录」时，在资源管理器中打开并选中该文件（Windows）；其它平台仍打开父目录。
- 非目标：改「打开文件」行为；非 Windows 专用选中 API。

## 用户故事

作为使用者，我点「打开所在目录」希望一眼看到刚传的那个文件，而不是面对一堆文件自己翻。

## 行为

1. `landrop://reveal/`：Windows 用资源管理器 `/select,完整路径`；失败则回退打开父目录。
2. 其它平台：保持打开父目录。
3. 路径不存在：静默忽略（与现网一致）。

## 验收标准

- [ ] S1：Windows 上点「打开所在目录」，资源管理器打开且该文件被选中。
- [ ] S2：「打开文件」仍用默认程序打开文件本身。
- [ ] S3：路径已删时点击无崩溃。
