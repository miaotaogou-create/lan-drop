# 设备行延迟图标与文字对齐

- 状态：已实现（待手测）
- 背景：侧栏设备行「⚡ 3.0ms」用彩色 emoji，Windows 下图标与数字垂直中心错位。
- 目标：闪电图标与延迟文字同轴居中；离线仍只显示「离线」文案。
- 非目标：改 Ping 探测逻辑或数值格式。

## 验收

- [ ] P1：在线行闪电与「Nms」垂直中心对齐。
- [ ] P2：离线行仍为「离线」，无错位闪电图标。
- [ ] P3：Ping 定时刷新后对齐仍正确。

## 影响范围

- `src/uiicons.{h,cpp}`：自绘闪电图标
- `src/mainwindow.cpp`：设备行 ping 布局（图标 + 文字）
