# 选中对端后聚焦输入框

- 状态：已实现（待手测）
- 背景：点左侧设备后还要再点一次输入框才能打字，连续聊天时多余。
- 目标：选中对端（含切换）后，输入框自动获得焦点。
- 非目标：托盘恢复窗口时强制抢焦点策略变更。

## 用户故事

作为使用者，我点开某人后希望立刻能打字回消息。

## 行为

1. 左侧列表选中变化导致会话刷新时：若有有效对端，`m_input` 获得焦点。
2. 无对端 / 空态：不抢焦点。
3. 不改变发送快捷键与其它控件行为。

## 验收标准

- [ ] F1：点击列表某对端后，可直接键盘输入，无需再点输入框。
- [ ] F2：在两台对端间切换后，输入框仍保持可直接输入。
