# 左侧设备栏宽度记忆

- 状态：已实现（待手测）
- 背景：左侧设备列表固定 300px，人多或名字长时想拉宽，下次启动又缩回去。
- 目标：侧栏可拖拽调宽，进托盘/退出时写入设置，下次启动恢复。
- 非目标：
  - 记住纵向分割（聊天/输入）比例
  - 多套布局方案
  - 改列表项 UI

## 用户故事

作为使用者，我希望把左侧设备栏拉到舒服的宽度后，下次打开还是那样。

## 行为

1. 主区左右之间可拖分割条调侧栏宽度。
2. 侧栏宽度限制约 220–480px，避免拖没或占满。
3. ✕ 进托盘或退出时，与窗口几何一并写入 `settings.json`（字段如 `sideWidth`）。
4. 启动时若有合法 `sideWidth` 则恢复；否则默认 300。
5. 设置页改其它项保存时不丢该字段。

## 验收标准

- [ ] W1：拖宽侧栏后进托盘再打开，宽度基本一致。
- [ ] W2：不能拖到小于约 220 或大于约 480。
- [ ] W3：删掉 `sideWidth` 后启动为默认约 300，不崩。
- [ ] W4：`--self-check` 覆盖 `sideWidth` 读写往返。
