# 取消与清空排队文案更易区分

- 状态：已实现（待手测）
- 背景：「取消」与「清空排队」并列时，「取消」二字太短，容易点错成停掉当前大文件；其实取消会停当前并清整队。
- 目标：按钮文案与悬停说明把两种动作说清楚。
- 非目标：改取消/清空的实际语义（仍见既有需求）。

## 用户故事

作为使用者，我传大文件时希望一眼分清「只清后面排队」和「全停」。

## 行为

1. 原「取消」按钮文案改为「取消全部」（聊天页与文件页一致）。
2. 「取消全部」悬停：说明会中止当前发送并清空排队。
3. 「清空排队」悬停：说明只清排队、当前文件继续传。
4. 实际逻辑不变。

## 验收标准

- [x] A1：发送中有排队时可见「取消全部」与「清空排队」（实现已对齐，待手测）
- [x] A2：悬停文案能区分两种后果（实现已对齐，待手测）
- [x] A3：点「清空排队」当前仍继续；点「取消全部」当前中止且队列空（实现已对齐，待手测）
