# 托盘 Toast 白卡、文件操作 chip 与进度含文件名

- 状态：已实现（待手测）
- 背景：托盘自绘提示仍是深色扁框，与主界面白卡语言断层；文件卡底操作仍是灰蓝文字链；进度胶囊只写「发送中」，当前文件名藏在 tooltip。
- 目标：Toast 改为白卡+阴影并可点；文件操作为圆角 chip；进度主文案前置截断文件名。
- 非目标：系统托盘气泡替换；文件卡整卡重绘；改传输协议。

## 用户故事

作为使用者，我希望：后台收到文件时右下角提示和主界面是一套风格，且知道能点；文件卡上的打开/目录一眼像按钮；传多个文件时不用悬停就知道正在传哪个。

## 行为

1. 托盘 Toast：白底圆角+轻阴影；标题/正文深色；底部「点击打开」；点击行为不变。
2. 文件卡完成态：打开 / 目录 / 复制路径 为浅底圆角 chip（主操作偏蓝）。
3. 发送/接收进度胶囊：主文案以截断文件名开头，再接速率/ETA/排队；详情仍可在 tooltip。
