# 网页共享：添加文件与拖放

- 状态：已实现
- 背景：「+ 添加文件到共享」与虚线区文案像「加文件」，实际却是选目录；拖放无效。
- 目标：点添加或点虚线区 → 多选本机文件，复制进共享目录并刷新列表；支持拖文件到虚线区/列表区；列表可删单文件。仍用单目录模型。
- 非目标：
  - 散文件虚拟列表（仍是磁盘上一目录）
  - 拖文件夹整树递归（仅顶层文件；拖入文件夹时只取该文件夹下的顶层文件）
  - 改 HTTP `/share/` 协议

## 用户故事

作为使用者，我希望把几个文件拖进或点选进网页共享，手机扫码就能下，而不必先整理一个专用文件夹。

## 行为

1. **默认共享目录**：若当前未开启共享，首次添加时在下载目录下创建 `lan-drop-share` 并设为共享目录。
2. **添加文件**：多选文件 → 复制到共享目录（重名自动加 `_2` 等后缀）→ 列表与状态变为运行中。
3. **拖放**：虚线区与文件列表区域接受本地文件拖入，行为同添加文件。
4. **删除**：每行右侧删除按钮，删除共享目录中该文件（不删源文件）。
5. **暂停**：仍清空 `shareDir`；再次添加会复用上次目录或重建默认目录。

## 验收标准

- [x] F1：无共享时点「添加文件」，选 1～N 个文件后列表出现对应文件名，状态为运行中
- [x] F2：浏览器打开 `/share/` 能下到刚添加的文件
- [x] F3：把文件拖到虚线区或列表区，效果同 F1
- [x] F4：点行内删除后该文件从列表与 `/share/` 消失，源路径文件仍在
- [x] F5：同名再添加不覆盖，出现带后缀的新文件名
