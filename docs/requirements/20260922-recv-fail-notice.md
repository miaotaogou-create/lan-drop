# 接收失败可见提示

- 状态：已实现（待手测）
- 背景：收文件已有「接收中 N%」卡；对端断线或写盘失败时会静默删掉进度卡，用户以为卡住又消失了。
- 目标：接收失败后去掉进行中卡，并在该会话插入红色失败提示（文件名 + 简短原因）；可选播通知声 / 托盘提醒。
- 非目标：
  - 接收失败「重试」按钮（本机无法主动重拉对端上传）
  - 改传输协议或自动恢复半成品文件
  - 自定义铃声

## 用户故事

作为接收方，我希望传一半断了时聊天里有明确失败说明，而不是进度条突然没了。

## 行为

1. `fileReceiveFailed`：移除对应路径的进行中 `InFile` 卡（若有）。
2. 向该会话 `appendMsg` 一条 `Fail`：文案含文件名与「对端中断或写盘失败」类说明；**不**带本地可重试路径（避免出现无效「重试」链）。
3. 若通知声开：播一次；若窗口不在前台：可托盘提醒「接收失败」。
4. 失败条照常可落盘进 `chat.json`。

## 验收标准

- [ ] F1：收文件进行中人为中断对端发送，本机进度卡消失并出现红色失败条。
- [ ] F2：失败条文案含文件名，且无「重试」链接。
- [ ] F3：通知声开时可听到一声；关则无声。
- [ ] F4：退出再开，失败条仍在（已落盘）。
