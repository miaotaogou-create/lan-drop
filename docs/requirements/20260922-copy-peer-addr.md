# 会话顶栏复制对端地址

- 状态：已实现（待手测）
- 背景：本机胶囊已可复制；会话顶栏的 `IP:端口` 仍只能眼看手抄，给别人或另开「加 IP」时不方便。
- 目标：点击当前会话顶栏地址即可复制该对端的 `IP:端口`，反馈与本机复制一致。
- 非目标：
  - 复制设备名 / 主机名
  - 改直连胶囊整段可点（本轮只做顶栏 `peerAddr`）
  - 聊天记录落盘

## 用户故事

作为使用者，我希望点一下当前对端地址就能粘贴出去，和复制本机地址一样省事。

## 行为

1. 已选对端时，会话顶栏地址（如 `192.168.1.8:8848`）为可点击（手型）；悬停提示「点击复制对端 IP:端口」。
2. 单击：剪贴板写入当前对端的 `IP:端口`（与顶栏文案一致）。
3. 成功：短暂「已复制 …」提示。
4. 无选中对端时不可点到该控件（页面为空状态）。

## 验收标准

- [ ] P1：选中对端后点顶栏地址，剪贴板为该 `IP:端口`。
- [ ] P2：有「已复制」反馈。
- [ ] P3：切换对端后再点，复制的是新对端地址。
- [ ] P4：与本机胶囊复制互不干扰。
