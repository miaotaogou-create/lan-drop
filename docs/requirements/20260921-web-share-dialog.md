# 网页共享对话框（对齐参考图）

- 状态：已实现
- 背景：当前「网页共享」是系统原生小表单（选目录、复制链接、开/停），与参考图「本机 HTTP 网页共享服务」差距大。
- 目标：对话框**布局与文案**对齐参考图；继续用现有「共享一个目录、浏览器列顶层文件并下载」。
- 非目标（历史；部分已由 `20260922-share-add-files.md` 覆盖）：
  - 把共享模型改成「任意散文件列表」（仍是一个目录）
  - 新的第三方包

## 用户故事

作为使用者，我希望在统一风格的弹窗里看到局域网地址、可扫的二维码和当前共享的顶层文件，并能复制地址、用本机浏览器打开、暂停或关闭。

## 布局（对照参考图）

1. **顶栏**：`share-badge.svg`（蓝底圆角 + 白色三节点分享连线）；标题「本机 HTTP 网页共享服务」；其右侧绿色状态「● HTTP 服务运行中 / 已暂停」；副标题「局域网内任意手机、平板或电脑，打开浏览器或扫码即可下载本机共享的内容」；右上关闭
2. **上排两卡等高**
   - 左卡：地球图标 +「局域网访问地址（浏览器直接输入）：」；大号蓝色 `http://<本机IP>:<端口>/share/`；灰字「绑定网卡: … · 端口: … (同一局域网下均可访问)」；底栏左对齐「复制网址」「本机浏览器自测」（实心蓝）
   - 右卡：二维码（编码上述地址）；底「手机 / 平板扫码」+「无需安装 App，相机扫码即可下载」
3. **文件列表**：标题「当前共享的文件列表」+ 数量胶囊；提示「支持拖动文件到此处」；右侧「+ 添加文件到共享」（多选文件并复制进共享目录）；下列顶层文件名与大小，行内可删除；虚线区支持拖放或点击选文件
4. **底栏**：左「暂停 HTTP 服务 / 开启 HTTP 服务」（按钮带 `power.svg` 电源图标）；中「仅局域网有效，随开随关」；右深色「关闭窗口」

窗体：无边框圆角 + `WA_TranslucentBackground`（同设置对话框，避免四角黑三角）。

## 行为

| 操作 | 结果 |
|------|------|
| 添加文件 / 点虚线区 / 拖入文件 | 复制进共享目录（无则创建 `下载目录/lan-drop-share`），列表刷新，状态运行中 |
| 行内删除 | 删除共享目录中该文件，不删用户源文件 |
| 复制网址 | 剪贴板为上述 URL |
| 本机浏览器自测 | 用系统浏览器打开该 URL |
| 暂停 | 清空共享目录指针，列表空，状态为已暂停 |
| 关闭窗口 / 右上关闭 | 仅关窗，不改变共享状态 |
| 打开时已有共享目录 | 直接列出文件并显示运行中 |

二维码必须能被手机相机识别为上述 URL。详见添加文件：`20260922-share-add-files.md`。
