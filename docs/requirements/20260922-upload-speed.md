# 发送进度显示速率

- 状态：已实现（待手测）
- 背景：大文件只有百分比，分不清是卡住还是慢。
- 目标：发送进度文案附带当前大致速率（如 `1.2 MB/s`）。
- 非目标：精确 ETA UI；接收侧进度见 `20260922-recv-speed.md`。

## 用户故事

作为使用者，我传大文件时希望看到大概多快，好判断要不要换网线或取消。

## 行为

1. 发送进度回调时估算速率（短窗口滑动），写入进度文案：`正在发送 foo  42% · 1.2 MB/s`；有排队时仍保留「排队还剩 N」。
2. 刚开始或窗口过短：可不显示速率，避免乱跳。
3. 取消/结束：进度清空，无残留。

## 验收标准

- [ ] V1：传较大文件时进度出现 `xx/s` 量级速率。
- [ ] V2：有排队时速率与「排队还剩」可同时出现。
- [ ] V3：传完或取消后进度区清空。
