# 文件卡复制路径

- 状态：已实现（待手测）
- 背景：打开/所在目录已有；有时只需把完整路径贴到别处（终端、工单），还要再开资源管理器复制。
- 目标：文件卡增加「复制路径」，写入剪贴板本机绝对路径。
- 非目标：复制相对路径、改打开行为。

## 用户故事

作为使用者，我希望一点就能复制刚收到/发出的文件完整路径。

## 行为

1. 有本机路径的文件卡：在「打开所在目录」旁增加「复制路径」。
2. 点击：剪贴板为该文件绝对路径（与本机路径分隔符习惯一致即可）。
3. 进度中/无路径：不显示该链接。
4. 路径不存在时仍可复制字符串（便于排查）；不弹框。

## 验收标准

- [ ] P1：收件文件卡可见「复制路径」，点击后剪贴板为绝对路径。
- [ ] P2：发件文件卡同样可复制源路径。
- [ ] P3：发送中进度卡无「复制路径」。
