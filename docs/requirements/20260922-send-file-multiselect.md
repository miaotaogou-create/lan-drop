# 发送文件支持多选

- 状态：已实现（待手测）
- 背景：点「发送文件」一次只能选一个；要发多个得反复点，已经支持排队却用不了对话框多选。
- 目标：「发送文件」对话框允许多选，选中的路径一次入队（空闲启动 / 忙时追加）。
- 非目标：文件夹对话框多选；拖放行为变更。

## 用户故事

作为使用者，我想一次选出几个文件发出去，不要点好几轮。

## 行为

1. 「发送文件」使用系统多选文件对话框。
2. 选中 1 个：行为与现网单文件一致（可无「开始发送」系统条）。
3. 选中多个：入队；空闲时提示「开始发送文件（N 个）」并依次发；忙时走入队提示。
4. 取消对话框：无变化。

## 验收标准

- [ ] M1：发送文件对话框可多选。
- [ ] M2：一次选 3 个，空闲时依次发出；系统条有开始发送（N 个）。
- [ ] M3：发送中再点发送文件多选 2 个，入队并续传。
- [ ] M4：对话框点取消，无发送、无系统条。
