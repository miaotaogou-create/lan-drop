# 文件夹打包异步且可取消

- 状态：已实现（待手测）
- 背景：打包在主线程等待，大目录会卡死界面。
- 目标：`tar` 异步执行；进度显示「正在打包…」；取消可 kill 进程。
- 非目标：打包进度百分比；并行多进程打包。

## 用户故事

作为使用者，我打包大工程时希望界面还能动，并能中途取消。

## 行为

1. 开始打包后立即返回 UI；进度区显示「正在打包…」，「取消」可用。
2. 点取消：终止打包进程、删未完成 zip、进度清空、系统条可记「已取消打包」。
3. 打包成功后再入发送队列；失败提示原因且不入队。
4. 自检仍可用同步 `zipDirectory`（小目录）。

## 验收标准

- [ ] A1：打包过程中窗口可拖动/点击（不假死）。
- [ ] A2：打包中点取消，不产生有效 zip 入队。
- [ ] A3：小目录打包成功仍可发送。
