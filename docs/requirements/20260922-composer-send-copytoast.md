# 输入卡去硬线、发送禁用灰化、复制迷你白卡

- 状态：已实现（待手测）
- 背景：Composer 白卡外仍有顶线、工具条灰带，像两层；发送禁用底灰但箭头仍亮；复制地址仍是系统 tooltip，与白卡语言脱节。
- 目标：输入区整卡更干净；禁用发送整颗发灰；复制反馈改迷你白卡 Toast。
- 非目标：文件 Tab 再加数量胶囊；改托盘大 Toast 布局。

## 用户故事

作为使用者，我希望：输入区是一块干净浮卡；没字时发送钮不像可点；复制后反馈和界面同风格。

## 行为

1. `#composer` 去掉 `border-top`；`#composerToolBar` 背景改白（细分线更淡）。
2. `syncSendBtn`：禁用时发送图标半透明。
3. 迷你白卡提示（约 1.6s）：本机/对端地址复制、右键复制、聊天复制、粘贴截图反馈；悬停说明仍用系统 tooltip。
4. 窗口外框描边略收软（`#e2e8f0`）。
