# 顶栏按下态、危险菜单红字与离线条层次

- 状态：已实现
- 背景：工具钮/跳底已有 pressed，本机胶囊与对端地址仍无按下反馈；右键「清空/删除」悬停仍变蓝，与危险确认红钮不一致；离线条姓名与地址同色偏糊。
- 目标：可点顶栏区有按下态；危险菜单项常态红、悬停浅红底；离线提示三级可读；滚动条拖拽加深。
- 非目标：改复制/清空逻辑；重做会话顶栏布局。

## 用户故事

作为使用者，我希望点本机地址、共享钮时有按下反馈；右键清空/删除一眼是危险项；对方离线时姓名比地址更抢眼。

## 行为

1. `#hostPill` / `#peerAddr` 按下时加深（属性 `pressed`）；`#shareBtn` 有 `:pressed`；`copied` 绿闪优先。
2. `addDangerMenuAction`：清空聊天、删除节点为红字，悬停浅红底不进蓝选。
3. 离线条：前缀琥珀、姓名加粗深琥珀、地址浅色等宽；滚动条 handle `:pressed` 更深。

## 验收标准

- [x] P1：按住本机胶囊/对端地址/共享钮有更深填充，松手恢复
- [x] P2：右键菜单危险项红字，悬停浅红底
- [x] P3：离线条姓名加粗、地址更淡，可读层级清晰
- [x] P4：拖拽滚动条滑块时颜色加深
