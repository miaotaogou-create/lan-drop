# 文字气泡一键复制

- 状态：已实现（待手测）
- 背景：普通文字气泡画成图片，无法拖选；互传命令/路径时只能靠记忆或重打。代码块已有复制。
- 目标：普通文字气泡旁提供「复制」，写入剪贴板原文。
- 非目标：改成可选中 HTML 文本气泡；富文本选区。

## 用户故事

作为使用者，我希望对方发来的命令或路径一点就能复制。

## 行为

1. 非代码围栏的文字气泡（收/发）：气泡下方或旁侧显示「复制」链接。
2. 点击：剪贴板为该条完整原文。
3. 代码围栏气泡：仍用现有块内「复制」，不重复加一条。
4. 空文本不显示。

## 验收标准

- [ ] T1：收到普通文字后点「复制」，剪贴板与原文一致。
- [ ] T2：自己发出的普通文字也可复制。
- [ ] T3：``` 代码块仍用块内复制，行为不变。
