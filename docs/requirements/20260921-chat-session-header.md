# 会话区顶栏与直连横幅（对齐参考图）

- 状态：已实现（界面壳；Ping / 文件列表功能仍非本轮）
- 背景：参考图右侧选中对端后，消息列表上方有对端信息顶栏、模式切换按钮、以及「已建立局域网直连」横幅；当前 Qt 客户端右侧只有空白 `QTextEdit`，顶栏缺失。
- 目标：先把**界面对齐**参考图聊天框顶部结构，再实现 Ping / 文件传输列表等真实功能。
- 非目标（本轮不做）：
  - 真实 Ping 测速、网卡链路类型探测
  - 文件传输矩阵页的真实列表与进度
  - 聊天气泡化、文件卡片、代码块样式
  - 本机头像「M」与消息气泡布局改造

## 用户故事

作为使用者，我希望选中一台附近设备后，右侧聊天区顶部立刻能看到对端是谁、地址多少、当前是聊天还是传文件模式，以及已建立直连的提示，以便确认会话对象，再开始发消息。

## 布局（自上而下）

1. **会话顶栏**（白底、底部分割线）
   - 左：对端头像（与左侧列表同一套完整 SVG，44×44）
   - 中上：对端显示名（粗体）+ 在线绿点 + `IP:端口`（浅灰底小胶囊或等宽灰字）
   - 中下：次行元信息，占位文案：`主机名或状态  ·  Ping —  ·  链路 —`（真实数据后续接）
   - 右：两个描边按钮
     - 「即时聊天」（会话气泡图标）
     - 「文件传输 (n)」（文件图标；`n` 本轮固定 `0`）
2. **直连横幅**（浅绿底、绿边、居中或左对齐）
   - 文案：`已建立局域网直连：{名称} ({IP}:{端口})`
   - 左侧绿色对勾圆标
3. **内容区**
   - 「即时聊天」：现有消息 `QTextEdit` + 底部输入区（本轮不改交互）
   - 「文件传输」：空态占位页（说明后续实现），不接真实传输列表

## 交互（本轮）

- 选中左侧对端 / 刷新列表后，顶栏与横幅随当前对端更新；无对端时不显示（仍走空态页）。
- 点击「即时聊天」/「文件传输」仅切换右侧内容壳，高亮当前按钮；不发起网络请求。
- 对端离线时：绿点改为琥珀色或灰点；横幅仍可显示「已选中对端」文案（本轮可用同一句直连文案，离线时把句首改为「当前对端」即可，待确认见下）。

## 验收标准

- [x] C1：选中对端后，消息列表上方出现会话顶栏（头像、名称、地址）
- [x] C2：顶栏右侧可见「即时聊天」「文件传输 (0)」两个按钮
- [x] C3：顶栏下方可见绿色「已建立局域网直连：…」横幅，含名称与 `IP:端口`
- [x] C4：切换两个按钮可在聊天页与文件传输占位页之间切换，且按钮高亮随切换变化
- [x] C5：切换左侧另一台设备时，顶栏名称/地址/头像与横幅同步更新
- [x] C6：本轮不要求真实 Ping、链路类型、文件传输列表数据
