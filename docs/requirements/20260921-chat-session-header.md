## 用户故事

作为使用者，我希望选中一台附近设备后，右侧聊天区顶部立刻能看到对端是谁、地址多少、当前是聊天还是传文件模式，以及已建立直连的提示。

## 布局（自上而下）

1. **会话顶栏**（白底、底部分割线）
   - 左：对端头像（44×44）
   - 中上：显示名 + 在线绿点 + `IP:端口`
   - 中下：`{hostname}  ·  Ping …  ·  {链路}`（见 `20260922-peer-hostname.md`、`20260921-ping-and-files.md`）
   - 右：「即时聊天」「文件传输 (n)」
2. **直连胶囊**：居中白底 + 绿盾（见聊天气泡文档）
3. **内容区**：即时聊天气泡区 / 文件传输列表
