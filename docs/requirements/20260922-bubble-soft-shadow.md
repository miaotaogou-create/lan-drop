# 气泡与文件卡轻阴影

- 状态：已实现（待手测）
- 背景：文字气泡与文件卡已圆角位图，但仍平贴灰底，层次弱。
- 目标：气泡、文件卡、代码块、系统提示胶囊加极轻阴影，消息更「浮起」。
- 非目标：重阴影/霓虹；改配色与左右对齐。

## 用户故事

作为使用者，我希望聊天区消息有轻微纵深，看起来更现代。

## 行为

1. 发出/收到文字气泡带轻阴影。
2. 文件卡壳、代码块、系统/失败胶囊同样轻阴影。
3. 阴影半透明、偏移小，不脏蓝底气泡。
