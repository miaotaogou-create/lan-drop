# 一键复制本机地址

- 状态：已实现（待手测）
- 背景：告诉别人「加我 IP」或填跨网段节点时，要自己记顶栏里的地址，容易抄错。
- 目标：点击顶栏「本机」胶囊即可复制 `IP:端口` 到剪贴板，并有短暂已复制反馈。
- 非目标：
  - 复制设备名、二维码进顶栏
  - 多网卡选择器（仍用现有 `localIpText` 所选地址）
  - 改发现/传输端口逻辑

## 用户故事

作为使用者，我希望点一下本机地址就能粘贴给别人或填进「加 IP」，少打字、少出错。

## 行为

1. 顶栏本机胶囊可点击（手型光标）；悬停提示「点击复制本机 IP:端口」。
2. 单击：剪贴板写入当前展示所用的 `IP:端口`（端口为设置中的传输端口）。
3. 复制成功：鼠标旁短暂提示「已复制」，或等价可见反馈；胶囊文案不必永久改掉。
4. IP 不可用时（空）：不写剪贴板，可提示暂不可用。

## 验收标准

- [ ] C1：点击本机胶囊后，剪贴板为 `x.x.x.x:端口`，与顶栏展示一致。
- [ ] C2：有「已复制」类短暂反馈。
- [ ] C3：点击胶囊不会误触发拖动无边框窗口。
- [ ] C4：改端口并保存后，再点复制得到新端口。
