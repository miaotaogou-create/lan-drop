# 窗口位置与大小记忆

- 状态：已实现（待手测）
- 背景：每次启动都是固定 1180×720，用户调好的位置与尺寸下次要重来。
- 目标：退出到托盘或真正退出前记住窗口位置、大小、是否最大化；下次启动按记忆恢复（非法/屏外则回退默认）。
- 非目标：
  - 多显示器复杂布局编辑器
  - 分会话记忆左侧栏宽度
  - 「有新消息回到底部」按钮（另开）

## 用户故事

作为使用者，我希望把窗口摆好、拉好大小后，下次打开还在原处，不必每次拖。

## 行为

1. 点 ✕ 进托盘前：写入当前几何（若最大化则记最大化，并保留还原用的普通矩形）。
2. 托盘「退出」前：同样写入。
3. 启动：`settings.json` 有合法宽高则 `move`/`resize`；`windowMaximized` 为真则再最大化。
4. 宽高小于最小窗口或坐标明显不可用时：忽略记忆，用默认 1180×720。
5. 设置页改其它项保存时：不丢已加载的几何字段。

## 验收标准

- [ ] G1：拉大窗口并挪到别的位置 → ✕ 进托盘 → 再打开，位置与大小基本一致。
- [ ] G2：最大化后进托盘再打开，仍为最大化（或可还原到先前普通尺寸）。
- [ ] G3：删掉/损坏几何字段后启动，仍为默认大小且不崩。
- [ ] G4：`--self-check` 覆盖几何字段读写往返。
