# 输入区衬底、发出 meta 与侧栏副行收紧

- 状态：已实现（待手测）
- 背景：Composer 白底与输入浮卡同色，卡浮感弱；发出消息 meta 仍带「我」占位；侧栏副行写「在线」与排序/图标重复；发送钮禁用仍手指光标。
- 目标：输入卡更浮；发出 meta 只留时间+徽标；侧栏只在离线时标「离线」；禁用发送为箭头光标。
- 非目标：重做侧栏自定义 item；改会话顶栏结构。

## 用户故事

作为使用者，我希望：输入卡一眼浮在聊天底上；自己的消息不必再标「我」；设备列表更干净；空输入时发送钮不像可点。

## 行为

1. `#composer` 背景改为与聊天区同色 `#f1f5f9`，突出输入浮卡。
2. 发出文字/文件 meta：不显示「我」，仅时间 + 发送中/已送达徽标。
3. 侧栏副行：去掉「在线」；离线仍显示「离线」；手动/置顶/系统/标签保留。
4. 发送钮禁用时 `ArrowCursor`，可用时仍为手型。
