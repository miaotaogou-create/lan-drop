# 对端列表未读角标

- 状态：已实现（待手测）
- 背景：正在看 A 时 B 发来消息/文件，列表无提示，只能靠托盘或自己点开才发现。
- 目标：非当前会话（或窗口隐藏时当前会话）收到文字/文件后，左侧对端名旁显示未读条数；点进该对端后清零。
- 非目标：
  - 系统托盘图标角标（Windows 需额外注册）
  - 未读持久化到磁盘
  - 抖动/系统消息计入未读

## 用户故事

作为使用者，我希望一眼看出哪个对端有新消息，点进去就能看，不必挨个点开。

## 行为

1. 收到 `InText` / `InFile`，且（对端不是当前选中 **或** 主窗口不可见）→ 该对端未读 +1。
2. 选中该对端（含托盘提示跳转）→ 该对端未读清零。
3. 仅从托盘图标恢复窗口（未点收件提示）→ 当前选中对端未读清零。
4. 列表展示：名称后显示未读数（如 `qwer-pc · 2`）；为 0 不显示。
5. 抖动、发出消息、失败/系统提示不计入未读。

## 验收标准

- [ ] U1：看 A 时 B 发文字，B 名称旁出现未读；点 B 后消失且聊天可见新消息。
- [ ] U2：窗口隐藏时当前对端发文件，恢复后未读已清（或点进该对端后清）；列表在隐藏期间曾显示未读。
- [ ] U3：点托盘收件提示跳到发送方后未读为 0。
- [ ] U4：抖动不增加未读。
