# 记住上次选中的对端

- 状态：已实现（待手测）
- 背景：每次启动或列表刷新后常落到列表第一项，常用对端要再点一次。
- 目标：记住最近一次选中的对端（`IP:端口`）；启动后若该对端仍在列表中则自动选中并打开会话。
- 非目标：
  - 持久化聊天记录本身（仍仅内存）
  - 对端不在列表时自动加手动节点
  - 多账号/多配置档案

## 用户故事

作为使用者，我希望打开软件就回到上次聊的那台机器，少点一次列表。

## 行为

1. 用户选中某对端（含托盘跳转选中）后，将 `IP:端口` 写入设置（可与窗口几何同存，或在选中时轻量保存）。
2. 启动完成设备列表后：若 `lastPeer` 仍在当前列表（含手动/发现），选中它并展示会话；否则选第一项（与今日无记忆时一致）。
3. `refreshPeers` 周期性刷新时：优先保持当前选中；当前为空时再尝试 `lastPeer`，避免把用户刚点的冲掉。
4. 非法或空 `lastPeer`：忽略。

## 验收标准

- [ ] L1：选中对端 B → 退出再开，若 B 仍在列表则自动选中 B。
- [ ] L2：B 已不在列表时，行为回退到选第一项（或不选），不崩。
- [ ] L3：运行中手动改选 A，刷新列表后仍停在 A（不无故跳回旧 lastPeer）。
- [ ] L4：`--self-check` 覆盖 `lastPeer` 字段读写。
