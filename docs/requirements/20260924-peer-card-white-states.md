# 设备行白卡三态与 IP 对比度

- 状态：已实现（待手测）
- 背景：未选设备行呈水洗蓝（像半选），无边框融进侧栏灰底；IP 用细等宽淡字，对比度不足。
- 目标：默认纯白卡 + 细灰边；悬停浅灰；选中才浅蓝底 + 蓝边；IP/设备名加深扎实。
- 非目标：改搜索框；改发现逻辑；重做头像。

## 行为

1. `#peerList::item`：默认 `#ffffff` + `1px #e2e8f0`；`:hover` `#f8fafc` + `#cbd5e1`；`:selected` `#eff6ff` + `1px #3b82f6`；圆角 10px。
2. 设备名：`#0f172a`，13px，字重 600。
3. IP：非等宽（Segoe UI / 雅黑 UI），12px，`#64748b`，抗锯齿。

## 验收

- [ ] W1：未选中行为白卡细灰边，无淡蓝底。
- [ ] W2：悬停浅灰；选中才有科技蓝底与蓝边。
- [ ] W3：IP 一眼可读，不发虚蒸发。
