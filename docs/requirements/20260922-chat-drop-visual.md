# 聊天区拖放虚线反馈

- 状态：已实现（待手测）
- 背景：聊天区已能拖文件发送，但拖入时界面无变化，用户不确定「松手会不会发出去」。
- 目标：拖着本地文件进入当前会话区时，出现虚线高亮与简短提示；离开或松手后消失。
- 非目标：
  - 未选对端的空状态页拖放高亮
  - 改变既有发送/排队逻辑
  - 网页共享弹窗样式大改（可保持现状）

## 用户故事

作为使用者，我希望把文件拖进会话时立刻看到「可以松手发送」的反馈，心里有底。

## 行为

1. 已选对端、会话页可见时：拖入含本地文件/文件夹的内容进入会话区（聊天/文件页/输入区所在区域）→ 显示蓝色虚线框 + 文案（如「松手发送到 {对端名}」）。
2. 拖出该区域或取消拖放 → 高亮消失。
3. 松手放下 → 高亮消失，并按现有逻辑发送（含未选对端/发送中提示）。
4. 仅拖非文件（如纯文本）→ 不出现高亮、不接受放下。
5. 不改变 D1–D4 既有拖放发送行为。

## 验收标准

- [ ] V1：选中对端后拖文件进入会话区，出现虚线框与「松手发送到 …」类提示。
- [ ] V2：拖出会话区后高亮消失；松手发送后高亮消失且文件仍按原逻辑发出。
- [ ] V3：在会话区内从聊天移到输入框，高亮不闪烁消失。
- [ ] V4：未选对端（空状态）拖文件无本高亮（或根本不在会话区）。
