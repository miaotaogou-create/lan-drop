# UI 图标约定（对齐参考稿）

- 状态：进行中（本轮：顶栏广播 Logo 左右弧；设备列表头像 + 设备类型角标）
- 风格：现代简约线性图标（参考 Lucide），蓝底 `#2563eb` / 白线，列表头像用色块底

## 已确认

1. **顶栏品牌 Logo**：蓝圆角方块 + 中心白点 + **左右两侧**各两道弧（广播 Radio），不是上下（Wi‑Fi）。
2. **本机胶囊**：笔记本线性图标。
3. **设备列表**：每条对端左侧为彩色圆角头像（名称首字）+ 右下角设备类型小标：
   - 笔记本 / 桌面：`Laptop`（`windows` / `linux` / `macos` 等）
   - 手机：`Smartphone`（`android` / `ios` / `iphone`）
   - 平板：`Tablet`（`ipad` / `tablet`）
4. **实现方式**：Qt Widgets 下用 `QPainter` 自绘（与现有窗口按钮一致）。本阶段不加 SVG 资源树；高分屏靠 `devicePixelRatio`。

## 非本轮

- 聊天气泡、文件卡片进度条、二维码、抖动窗口、发送文件夹等参考稿元素（另开需求）
- 引入 QtSvg + `.qrc` 全套 Lucide 文件（可选后续）

- [x] U3：本机胶囊仍为笔记本图标
