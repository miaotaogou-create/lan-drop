# UI 图标与聊天输入区（对齐参考稿）

- 状态：本轮输入区已落地；气泡/二维码仍待做
- 风格：现代简约线性图标（参考 Lucide），蓝底 `#2563eb` / 白线，列表头像用色块底

## 已确认

1. **顶栏品牌 Logo**：蓝圆角方块 + 中心白点 + **左右两侧**各两道弧（广播 Radio），不是上下（Wi‑Fi）。
2. **本机胶囊**：笔记本线性图标。
3. **设备列表**：每条对端左侧为彩色圆角头像（名称首字）+ 右下角设备类型小标：
   - 笔记本 / 桌面：`Laptop`（`windows` / `linux` / `macos` 等）
   - 手机：`Smartphone`（`android` / `ios` / `iphone`）
   - 平板：`Tablet`（`ipad` / `tablet`）
4. **聊天输入区**（对齐参考图）：
  - 上方工具行：左「发送文件 / 发送文件夹 / 抖动窗口」（图标+文字）；Enter / Shift+Enter 说明见输入框悬停（`20260922-composer-hint-esc.md`），不再常驻键帽条
  - `Enter` 与 `Shift+Enter` 行为不变：Enter 发送，Shift+Enter 换行
  - 下方圆角输入框；占位「向 {对端} 发送消息...」
  - **发送按钮在输入框内右下角**（浅蓝圆角 + 白色纸飞机），不在框外
5. **工具栏 4 图标**：Lucide SVG 资源（`icons/*.svg` → `:/icons/`）
   - 发送文件：`paperclip.svg` 描边 `#2563EB`
   - 发送文件夹：`folder-plus.svg` 描边 `#F59E0B`
   - 抖动窗口：`zap.svg` 描边 `#F59E0B`
   - 发送：`send.svg` 白描边，按钮底 `#93C5FD`
6. **顶栏「网页共享 (HTTP)」**：左侧 `globe.svg`（描边 `#2563EB`，地球/局域网访问），与按钮浅蓝底搭配
7. **实现方式**：工具栏与共享按钮用 Qt Svg 渲染资源；其余窗口按钮等仍可 `QPainter` 自绘。

## 行为补充

- Enter 发送，Shift+Enter 换行（多行 `QPlainTextEdit`）
- 「发送文件夹」：选目录后逐个发送顶层文件（不打包 zip）
- 「抖动窗口」：发约定文本 `__landrop_nudge__`，双方窗口轻抖
