# 聊天文件卡图片缩略图

- 状态：已实现（待手测）
- 背景：粘贴截图与收发图片仍只显示通用 FILE 卡，必须打开才能看内容，现场对图很不方便。
- 目标：常见图片在气泡内显示小缩略图，仍保留打开/目录/复制路径。
- 非目标：相册浏览、原图预览窗、视频封面、超过体积上限的强制解码。

## 用户故事

作为使用者，我粘贴或收到截图后希望在聊天里一眼看到图。

## 行为

1. 扩展名属于常见图片（png/jpg/jpeg/gif/bmp/webp）且本地路径可读、传输已完成时：文件卡内嵌缩略图（约宽 ≤240px，等比）。
2. 点击缩略图等同「打开文件」。
3. 原有文件名、体积、打开/目录/复制路径保留。
4. 发送/接收进行中、路径不可读、或文件过大（如 >12MB）时：不强制出缩略，退回普通 FILE 卡。
5. 缩略可落临时缓存，避免每次全图进 HTML。

## 验收标准

- [ ] I1：粘贴 PNG 发送完成后，己方气泡出现缩略图。
- [ ] I2：收到对方图片后，接收方气泡出现缩略图。
- [ ] I3：非图片文件仍为普通 FILE 卡。
- [ ] I4：打开/目录/复制路径仍可用。
