# 确认/提示弹窗统一为白卡风格

- 状态：已实现（待手测）
- 背景：设置、共享、加 IP 已是白卡+阴影，清空会话、删节点、文件夹选择、校验失败等仍用系统 `QMessageBox`，视觉割裂。
- 目标：提供轻量 info / warn / confirm / 多选按钮白卡；替换主路径上的系统框。
- 非目标：改文件选择器（`QFileDialog`）；重做设置/共享大弹窗结构。

## 用户故事

作为使用者，我希望：点「清空」「删除」或发送文件夹时弹出的框，和设置页是同一套现代白卡，而不是突然跳出系统灰框。

## 行为

1. 信息提示、警告、是/否确认、文件夹 zip/顶层/取消 均走统一白卡（圆角、阴影、主/次按钮）。
2. 确认类默认焦点在「取消」或次要安全侧（与原先 `No` 默认一致）。
3. 文案与原先语义不变。
