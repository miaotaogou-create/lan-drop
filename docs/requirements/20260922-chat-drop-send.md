# 聊天区拖放发送文件

- 状态：已实现
- 背景：发文件目前只能点「发送文件 / 发送文件夹」；网页共享弹窗已支持拖放，聊天区还没有。
- 目标：选中对端后，可把本地文件/文件夹拖进聊天区（含输入区）直接排队发送。
- 非目标：
  - 递归发送子目录全部文件（文件夹只取顶层文件，与现有「发送文件夹」一致）
  - 气泡内实时进度条
  - 拖放进空状态页（未选对端）

## 用户故事

作为使用者，我希望把文件拖进当前会话就能发出去，少点几次按钮。

## 行为

1. 已选对端且在会话区：聊天消息区与底部输入区接受拖放。
2. 拖入本地文件：直接发送；多个文件或文件夹顶层文件排队发送。
3. 未选对端：提示先选设备。
4. 正在上传中：进度区提示稍候（非模态，见 `20260922-busy-upload-soft.md`），不打断当前上传。
5. 多文件时系统消息提示开始发送数量。

## 验收标准

- [x] D1：选中对端后，拖一个文件进聊天区，对端能收到
- [x] D2：拖一个含多个文件的文件夹，顶层文件依次发送
- [x] D3：未选对端时拖放有提示；正在发送时提示稍候
- [x] D4：不改变既有「发送文件 / 发送文件夹」按钮行为
