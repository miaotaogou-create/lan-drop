# 默认窗口再缩小，并支持无边框边缘拖拽缩放

- 状态：已实现（待手测）
- 背景：无边框主窗口目前只能拖标题栏/最大化，边缘无法拉大小；默认/记忆尺寸仍偏大，聊天区空白过多。
- 目标：默认更紧凑；四边与四角可拖拽缩放（尊重最小尺寸）；缩放结果仍按既有几何记忆保存。
- 非目标：
  - 改回系统原生标题栏
  - 改气泡/侧栏内容密度
  - 强制覆盖用户已记住的合理自定义尺寸（仅钳制勿超出屏）

## 用户故事

作为使用者，我希望打开软件窗口别太大，并能像普通窗口一样拖边改大小，调好后下次还记得。

## 行为

1. 无记忆几何时：默认约 `880×560`；最小约 `680×440`。
2. 恢复记忆几何：宽高仍钳在当前屏可用区域约 **85%** 内。
3. 非最大化时：贴窗口外缘约 6px 内拖拽可改宽高（含四角斜向）；最大化时不响应边缘缩放。
4. 标题栏拖动、双击最大化、侧栏 splitter 行为保持不变，且与边缘缩放不互相抢。
5. 缩放后的几何仍走既有 `persistWindowGeometry` / 进托盘与退出写入。

## 验收标准

- [x] R1：清除记忆几何后启动，窗口约 880×560 量级，明显小于整屏（实现已对齐，待手测）
- [x] R2：非最大化时可拖四边/四角改变大小，且不低于最小尺寸（实现已对齐，待手测）
- [x] R3：最大化时拖边缘不改变大小；还原后可再拖（实现已对齐，待手测）
- [x] R4：拖到合适大小 → ✕ 进托盘 → 再打开，尺寸基本保持（实现已对齐，待手测）
