# 一键打开下载目录

- 状态：已实现
- 背景：收文件后常要找「文件落在哪」；目前只能进设置看路径，或点聊天里单条「打开所在目录」。
- 目标：顶栏与托盘提供「打开下载目录」，一键打开当前配置的落盘根目录。
- 非目标：改下载路径逻辑、文件管理器内高亮具体文件、收文件托盘气泡（另开需求）。

## 用户故事

作为使用者，我希望随时能打开下载目录，快速查看刚收到的文件。

## 行为

1. 顶栏（网页共享旁）有「打开下载目录」入口（图标按钮，悬停有提示）。
2. 托盘右键菜单有同名项，调用同一逻辑。
3. 点击后：确保目录存在（`mkpath`）→ 用系统文件管理器打开绝对路径。
4. 若打开失败：简短提示。

## 验收标准

- [x] O1：顶栏可见打开下载目录入口
- [x] O2：点击后打开当前设置中的下载目录（资源管理器）
- [x] O3：托盘菜单「打开下载目录」效果相同
- [x] O4：目录不存在时会先创建再打开
