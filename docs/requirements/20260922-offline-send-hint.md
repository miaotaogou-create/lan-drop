# 离线对端发送轻提示

- 状态：已实现（待手测）
- 背景：列表显示「离线」时仍可点发送，失败后才知对面没开；中间缺少一句提醒。
- 目标：向当前显示离线的对端发文字或文件时，先给一条非打断系统提示，不拦发送。
- 非目标：禁止离线发送；强制模态确认；改发现超时逻辑。

## 用户故事

作为使用者，我对着离线设备点发送时，希望先知道可能失败，而不是干等超时。

## 行为

1. 发文字、入队发文件（含拖放/粘贴/多选）时：若当前对端 `online()==false`，在该会话插一条系统条：「对方当前显示离线，发送可能失败；请确认对方已打开局域快传。」
2. 同一对端连续发送：同一次离线周期只提示一次（切走再回来或恢复在线后再次离线可再提示）。
3. 不弹模态，不阻止发送。
4. 对端在线：无此提示。

## 验收标准

- [ ] O1：选中离线对端发一句字，出现上述系统条且消息仍会发出（或按现网失败）。
- [ ] O2：紧接着再发文件，不再重复同一系统条。
- [ ] O3：在线对端发送无此系统条。
