# 细滚动条与在线折叠连接条

- 状态：已实现（待手测）
- 背景：默认 Windows 粗滚动条与近期白卡/胶囊观感不搭；在线时连接条与顶栏「在线」信息重复，占聊天高度。
- 目标：全局细圆角滚动条；对端在线时隐藏连接条，离线时保留暖色警示条；顶栏元数据在线绿/离线琥珀分色。
- 非目标：自定义滚动条拖拽逻辑；去掉离线警示。

## 用户故事

作为使用者，我希望列表和聊天滚动更精致，在线时多一点聊天区，离线时仍能一眼看到警示。

## 行为

1. 侧栏、聊天、文件等滚动条变细、圆角、浅灰柄。
2. 当前对端在线：隐藏连接条宿主，腾出纵向空间。
3. 当前对端离线：显示暖色「对方当前离线」连接条。
4. 顶栏元数据中「在线/离线」分色（绿/琥珀），其余仍灰。
