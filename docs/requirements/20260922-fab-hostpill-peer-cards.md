# 发送钮浮起、本机胶囊层次与列表行卡感

- 状态：已实现（待手测）
- 背景：输入壳已浮起，发送 FAB / 跳底钮 / 本机胶囊仍平贴；侧栏对端行选中偏「浅蓝条」；空会话仍写纯文字快捷键，`#keycap` 样式未真正现身。
- 目标：主发送与本机地址胶囊有轻阴影；列表行更像可选小卡；空会话画出 Enter 等 keycap。
- 非目标：完整 ItemDelegate 重绘；改发现协议。

## 用户故事

作为使用者，我希望：点发送时按钮有「主按钮」质感；一眼能点本机胶囊复制地址；侧栏选中设备像选中一张卡；空聊天里快捷键一眼能认。

## 行为

1. `#sendFab`、`#jumpBottomBtn` 应用与输入壳同参轻阴影。
2. `#hostPill` 应用轻阴影；悬停反馈保持。
3. 侧栏列表项：白底浅边；悬停/选中更清晰的卡感（圆角+左边条）。
4. 空会话引导卡：快捷键以 keycap 块绘制（Enter / Shift+Enter / Ctrl+V）。
