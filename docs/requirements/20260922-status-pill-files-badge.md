# 顶栏状态胶囊、空 meta 收起与文件数角标

- 状态：已实现
- 背景：顶栏「在线 · …」仍是纯文字+小点，和侧栏蓝胶囊、会话 chip 不同语系；无 hostname/标签时 peerMeta 仍占一行空高；文件 Tab「文件 · N」挤在分段钮里不够现代。
- 目标：发现状态改为绿/琥珀胶囊；无副信息时收起 meta；文件数改为 Tab 旁小蓝角标。
- 非目标：改发现逻辑；会话顶栏大改布局；远程桌面。

## 用户故事

作为使用者，我希望顶栏一眼看出是否正常在线；会话顶栏更紧凑；文件数量像未读角标一样好扫。

## 行为

1. `#statusPill`：短文案；`ok=true` 绿底，否则琥珀；完整说明进 tooltip。
2. `peerMeta` 无内容时 hide。
3. 文件 Tab 固定「文件」；`N>0` 旁侧蓝胶囊数字。

## 验收标准

- [x] T1：正常发现时顶栏为绿色状态胶囊
- [x] T2：端口异常时为琥珀胶囊，悬停有完整说明
- [x] T3：无 hostname/标签时顶栏不留空副行
- [x] T4：有文件记录时「文件」旁见蓝数字角标；零文件时无角标
