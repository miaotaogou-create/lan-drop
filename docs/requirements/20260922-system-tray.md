# 系统托盘常驻

- 状态：已实现
- 背景：点窗口关闭会直接退出进程，HTTP 与局域网发现随之停止，误关就收不到文件。
- 目标：关闭主窗口默认隐藏到系统托盘，后台继续接收；托盘可恢复窗口或真正退出。
- 非目标：
  - 设置里配置「关闭行为」并持久化
  - 托盘气泡弹通知（本轮仅首次隐藏时一条系统提示）
  - 最小化按钮也进托盘（任务栏最小化保持现状）

## 用户故事

作为使用者，我希望关掉窗口后软件仍在后台收文件，需要时再从托盘打开；明确要退出时再结束进程。

## 行为

1. 系统托盘可用时：点标题栏关闭（✕）→ 主窗口隐藏，托盘图标仍在；服务继续。
2. 托盘菜单：「显示主窗口」「退出局域快传」。
3. 单击或双击托盘图标 → 显示并前置主窗口。
4. 选「退出」→ 结束进程（释放端口）。
5. 系统不支持托盘时：关闭行为回退为直接退出（与旧版一致）。
6. 首次隐藏到托盘时，弹出一次系统托盘提示。

## 验收标准

- [x] T1：托盘可用环境下，点 ✕ 后窗口消失、托盘有图标、进程仍在
- [x] T2：托盘「显示主窗口」或单击/双击可恢复窗口
- [x] T3：托盘「退出」后进程结束，端口释放
- [x] T4：无托盘环境不崩溃，关闭即退出
