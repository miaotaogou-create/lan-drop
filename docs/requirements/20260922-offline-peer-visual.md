# 离线对端一眼可辨

- 状态：已实现（待手测）
- 背景：列表「离线」仅二字，色与在线差不多；会话顶栏绿点/直连胶囊在对端已离线时仍像「连着」，易误判。
- 目标：离线设备在列表更淡；会话顶栏元数据标明在线/离线；离线时直连胶囊改为「对方当前离线」提示。
- 非目标：禁止选中离线对端；改发现超时；隐藏离线设备。

## 用户故事

作为使用者，我希望扫一眼列表和会话顶栏就知道对方开没开软件。

## 行为

1. 列表：离线项文字用更浅灰色；在线保持原色。
2. 会话顶栏副行：在 Ping 前标明「在线」或「离线」。
3. 状态点：离线为非绿色（沿用现有 `makeStatusDot(false)`）。
4. 直连胶囊：对端在线仍为「已建立局域网直连…」；离线改为「对方当前离线：{名} ({地址})」类文案（暖色/灰系可辨）。
5. 仍可选中离线对端并尝试发送（离线发送提示见 `20260922-offline-send-hint.md`）。

## 验收标准

- [x] L1：列表中离线设备文字明显浅于在线（实现已对齐，待手测）
- [x] L2：选中离线对端，顶栏副行含「离线」，胶囊不为「已建立局域网直连」（实现已对齐，待手测）
- [x] L3：对端恢复在线后顶栏/胶囊恢复直连文案（实现已对齐，待手测）
