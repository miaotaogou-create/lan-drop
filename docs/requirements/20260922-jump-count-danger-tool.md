# 跳底条数、危险确认与工具钮禁用态

- 状态：已实现
- 背景：上翻后跳底钮只写「有新消息」不计数、无按下态；清空聊天确认主钮仍是蓝「清空」，误触风险高；未选对端时工具钮走系统灰，与发送 FAB 禁用语言不一致。
- 目标：跳底显示条数并有 pressed；危险操作用红主钮且默认焦点在取消；工具钮禁用为统一浅灰；传控钮与托盘 toast 补反馈。
- 非目标：改清空语义；远程桌面。

## 用户故事

作为使用者，我希望上翻时一眼知道积了几条新消息；清空前确认钮是红的、默认落在取消；没选设备时工具区灰得干净。

## 行为

1. 上翻期间每来一条新消息，跳底文案为「N 条新消息 ↓」；有 `:pressed`；回底后清零隐藏。
2. `appConfirm(..., danger=true)` 时确认钮为红；清空聊天走危险确认，默认焦点仍在取消。
3. `#toolBtn:disabled` 浅灰；`#cancelUploadBtn`/`#clearQueueBtn` 有 `:pressed`；托盘 toast 白卡悬停边框偏蓝。

## 验收标准

- [x] J1：上翻后连收多条，跳底显示对应条数，按下有反馈，点回底后消失
- [x] J2：清空聊天确认「清空」为红钮，默认焦点在「取消」
- [x] J3：未选对端时文件/文件夹/抖动为浅灰 ghost
- [x] J4：传文件时取消/清空排队按下有态；托盘 toast 悬停边框加深
