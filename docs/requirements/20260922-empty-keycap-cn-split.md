# 空态键帽中文、分割条与侧栏宽度自适应

- 状态：已实现
- 背景：聊天空态仍用 Enter / Shift+Enter 英文键帽，和全中文界面脱节；侧栏分割条过细难点；拉宽/收窄侧栏后副行芯片仍按旧宽度绘制，易裁切或留白。
- 目标：空态键帽改为动作语义中文，脚注补快捷键；分割条更好点、悬停更明显；侧栏宽度变化时副行按新宽度重绘。
- 非目标：改快捷键行为；自定义分割条拖柄控件；远程桌面。

## 用户故事

作为使用者，我希望空会话一眼看懂「发送 / 换行 / 粘贴」；拖侧栏时手感清晰；拉宽列表后状态胶囊不会裁切难看。

## 行为

1. 聊天空态键帽文案为「发送」「换行」「粘贴」；脚注标明「回车 · Shift+回车 · Ctrl+V」。
2. 水平分割条命中区略加宽；默认浅灰、悬停偏蓝，视觉更易找。
3. 侧栏列表可视宽度变化足够时，重绘设备行副行芯片（含宽度进内容签名）。

## 验收标准

- [x] K1：无消息会话空态见中文三键帽，脚注含回车相关说明
- [x] K2：拖侧栏分割条可点中，悬停颜色变化可感知
- [x] K3：明显拉宽/收窄侧栏后，设备副行芯片宽度随之更新且不闪成空白
