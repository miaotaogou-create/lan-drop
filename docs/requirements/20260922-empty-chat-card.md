# 聊天空会话位图白卡

- 状态：已实现（待手测）
- 背景：文件 Tab 空态已是带阴影白卡；聊天区空会话仍是居中灰字，与白卡体系不一致。
- 目标：无用户消息时显示圆角阴影白卡，标题+副文案引导发消息/拖文件。
- 非目标：空态插画资源包；改空态触发条件。

## 用户故事

作为使用者，我选中对端却还没聊过时，希望看到清晰、好看的引导，而不是一行淡字。

## 行为

1. 会话无文字/文件消息（可有系统条）：居中白卡「发消息，或把文件拖到这里」+ 副文案快捷键提示。
2. 有用户消息后不再显示该卡。
3. 视觉与文件 Tab 空态、未选对端空态同一语言。
