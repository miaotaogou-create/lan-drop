# 头像取机器名首字

- 状态：已实现（待手测）
- 背景：参考图头像为名称首字母/汉字（如 Ubuntu→U）；列表曾误用系统类型 SVG（树莓派「树」等）。聊天发出侧 meta 为「我」时，头像也应取本机设备名首字，而非「我」。
- 目标：列表、会话顶栏、聊天气泡头像一律取**机器/设备显示名**的第一个非空白字符（拉丁转大写，汉字原样）。
- 非目标：自定义上传头像；按 OS 换品牌 SVG。

## 用户故事

作为使用者，我希望对端和本机头像一眼能对上机器名首字，而不是系统发行版图标。

## 行为

1. 设备列表 / 会话顶栏：彩色圆角方 + 名称首字；右下角仍为笔记本/手机/平板小标（由 os 决定）。
2. 聊天收到：头像取对端名称首字（橙底）。
3. 聊天发出：文案仍可为「我」，头像取本机 `deviceName` 首字（蓝底）。
4. 名称为空时显示 `?`。

## 验收标准

- [ ] A1：列表里 `qwer-pc` 显示 `Q`（或名称首字），不是「树」/Ubuntu 标。
- [ ] A2：发出消息头像为本机设备名首字；meta 仍可显示「我」。
- [ ] A3：收到消息头像为对端名首字；中文名显示汉字。
