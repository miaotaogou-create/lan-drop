# 侧栏「附近设备」标题行对齐美化

- 状态：已实现（待手测）
- 背景：标题、绿色数字角标、「+ 加 IP」三者高度/色系/间距不一致，绿角标像「在线健康」却只是数量，看起来别扭。
- 目标：标题与数量成一组、垂直居中；数量角标改横胶囊并与加 IP 同蓝灰语言；加 IP 高度贴近标题行。
- 非目标：改加 IP 逻辑；侧栏大改版。

## 用户故事

作为使用者，我希望侧栏顶行干净整齐，一眼是「附近有几台」+「去加一台」，而不是三块各说各话的控件。

## 行为

1. 标题与数量紧挨（约 6px），整体左对齐；右侧 stretch +「+ 加 IP」。
2. 数量角标：横胶囊、字号约 11、有数时蓝底蓝字（对齐加 IP），为零时灰底灰字。
3. 三者 `AlignVCenter`；加 IP 高度约 26px（不再强撑 32px）。
4. 去掉绿色「成功感」数量底（数量 ≠ 在线状态）。

## 验收标准

- [x] H1：标题与数字垂直居中、间距紧凑（实现已对齐，待手测）
- [x] H2：有设备时数量为蓝系胶囊（非绿）（实现已对齐，待手测）
- [x] H3：0 设备时数量为灰胶囊（实现已对齐，待手测）
- [x] H4：「+ 加 IP」与标题行视觉同高、不抢戏（实现已对齐，待手测）
