# 侧栏「附近设备」标题行对齐美化

- 状态：已实现（待手测）
- 背景：标题与「+ 加 IP」因控件类型/字号/键盘加号基线不同而视觉偏上；数量角标已去掉。
- 目标：标题与「添加 IP」浅蓝小胶囊 `AlignVCenter` 同轴；用矢量加号替代键盘 `+`。
- 非目标：恢复数量角标；改加 IP 业务逻辑。

## 用户故事

作为使用者，我希望侧栏顶行干净整齐，「附近设备」与右侧添加入口水平同轴，不再感觉字往上飘。

## 行为

1. 左侧「附近设备」16px 粗体；右侧 stretch。
2. 「添加 IP」为 26px 高浅蓝胶囊（`#EFF6FF` / `#2563EB`），矢量 `plus-small` 图标 + 文案，悬停加深。
3. 标题与按钮均 `Qt::AlignVCenter`，不再与标题强制同字号同高。
