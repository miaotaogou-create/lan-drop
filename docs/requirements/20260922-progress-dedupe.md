# 发送进度条与气泡进度去重

- 状态：已实现（待手测）
- 背景：文件卡已有「发送中 N%」条，输入区上方仍刷「正在发送 文件名 N%」，同一数字说两遍，吵且挤。
- 目标：有气泡进度时，顶栏进度改偏「速率 / ETA / 排队」；无排队且无速率时用更短「发送中」。
- 非目标：去掉取消/清空排队；改气泡内进度；改接收进度文案结构。

## 用户故事

作为使用者，我传文件时想在气泡看百分比，顶栏只看还要多久、后面还排谁，不要两行重复刷同一个 N%。

## 行为

1. 发送中：顶栏不再重复「正在发送 文件名 N%」主体（百分比以气泡为准）。
2. 有速率/ETA：顶栏显示如 `发送中 · 12 MB/s · 约 8 秒`。
3. 有排队：仍附「排队还剩 N 个」+ 文件名预览与 tooltip（见 `20260922-queue-peek.md`）。
4. 尚无速率且无排队：顶栏简写 `发送中`（取消按钮仍在）。
5. 接收中：顶栏同样不重复「正在接收 文件名 N%」，改为 `接收中 · 速率 · ETA`（与发送对称）。
6. 接收中文案中的文件名可放在 tooltip。
