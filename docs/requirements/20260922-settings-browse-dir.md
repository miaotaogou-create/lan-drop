# 设置页下载目录浏览按钮

- 状态：已实现
- 背景：下载目录目前只能手敲路径，容易输错，也不方便改到其它盘。
- 目标：设置对话框里下载目录旁增加「浏览…」，用系统选文件夹对话框填入路径。
- 非目标：改落盘逻辑、自动创建校验以外的行为、改其它设置项。

## 用户故事

作为使用者，我希望点一下就能选下载目录，而不必手打完整路径。

## 行为

1. 「文件接收下载目录」输入框右侧有「浏览…」按钮。
2. 点浏览：打开选文件夹对话框；起始目录优先为当前输入框路径（若存在），否则为本机主目录。
3. 用户确认后，把所选绝对路径写入输入框；取消则不变。
4. 仍须点「保存并关闭」才真正写入配置。

## 验收标准

- [x] B1：设置对话框下载目录行可见输入框 +「浏览…」
- [x] B2：点浏览可选文件夹，确认后路径填入输入框
- [x] B3：取消浏览不改输入框；保存后下载目录生效（与既有 S4 一致）
