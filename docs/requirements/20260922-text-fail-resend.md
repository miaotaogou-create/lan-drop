# 文字发送失败可重发

- 状态：已实现（待手测）
- 背景：文件失败已有「重试」；文字乐观发送失败后只剩红条，原文被清掉，只能重打。乐观发送需求写过「含重试若适用」，此前文件需求把文字排除在外。
- 目标：文字发送失败条带「重发」，一点按原文再发一次；不打断输入框里正在打的草稿。
- 非目标：自动重试；编辑失败条原文；文件失败逻辑改动。

## 用户故事

作为使用者，我发文字失败后希望点一下「重发」，不必把整句再敲一遍。

## 行为

1. 文字 HTTP 发送失败：去掉乐观气泡后，失败条旁出现「重发」。
2. 点「重发」：用失败时的原文再走一遍乐观发送；**不覆盖**输入框里已有草稿。
3. 重发成功/失败表现与普通发文字一致。
4. 文件失败仍用「重试」，文案与链接与文字「重发」区分。
