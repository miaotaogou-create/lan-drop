# 自动本机 IP 跟对端同网段

- 状态：已实现（待手测）
- 背景：多网卡时「自动」仍取列表首项，常与当前对端不同段。
- 目标：未手动指定 `preferredLocalIp` 时，展示/复制优先选与当前对端同网段（/24）的本机 IPv4。
- 非目标：改 UDP 发现绑卡；精确按子网掩码（本轮用前三段匹配即可）。

## 用户故事

作为使用者，我连着 VPN 时点「自动」也希望抄给同事的是和他同一局域网的地址。

## 行为

1. `preferredLocalIp` 非空且仍在列表：仍用手动选择。
2. 为空（自动）：若有当前选中对端 IP，在本机 IPv4 中选与其对端前三段相同者；多个则取第一个匹配；无匹配则回退列表首项。
3. 无当前对端：回退列表首项。
4. 设置里「自动」说明可提「优先与当前设备同网段」。

## 验收标准

- [ ] A1：自动模式下选与本机不同网段的对端后，顶栏 IP 尽量切到同段。
- [ ] A2：手动指定 IP 时不随对端改。
- [ ] A3：无同段地址时仍显示某个本机 IP（不空白）。
