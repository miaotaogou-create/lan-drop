# 发送排队可见下几个文件名

- 状态：已实现（待手测）
- 背景：只有「排队还剩 N 个」，多选/连拖后不知道队里是什么。
- 目标：进度文案附带下 1～2 个文件名；tooltip 可看更多。
- 非目标：完整队列面板、逐项删除/重排。

## 用户故事

作为使用者，我批量发送时希望瞄一眼后面还要传哪些文件。

## 行为

1. 有排队时：进度在「排队还剩 N 个」后附带括号预览，最多 2 个文件名（过长截断），更多用「…」。
2. 进度控件 tooltip：列出排队文件名（可全列或前若干，过长截断单行名）。
3. 无排队时：不显示预览，tooltip 清空或仅当前发送名。

## 验收标准

- [ ] Q1：发送中再入队 ≥2 个，进度出现文件名预览。
- [ ] Q2：鼠标悬停进度可见排队名提示。
- [ ] Q3：清空排队后预览消失。
