# 发送进度显示排队剩余

- 状态：已实现（待手测）
- 背景：入队后只靠系统条知悉排队，进度区仍只显示当前文件百分比，看不出后面还有几个。
- 目标：正在发送且队列非空时，进度文案附带「排队还剩 N 个」。
- 非目标：队列详情列表、逐项取消。

## 用户故事

作为使用者，我往队列里丢了几个文件，希望一眼看到还要等多久（还剩几个），不必翻聊天系统条。

## 行为

1. `m_uploading` 且 `m_uploadQueue` 非空：进度文案形如「正在发送 foo.zip  42% · 排队还剩 2 个」。
2. 队列为空：文案与现网一致（仅文件名与百分比）。
3. 入队后立即刷新进度后缀；每传完一个剩余数减 1。
4. 「已在发送队列中」等轻提示仍可短暂覆盖进度区（与现网一致，随后百分比回调会盖回）。

## 验收标准

- [ ] R1：发送中再入队 2 个，进度出现「排队还剩 2 个」。
- [ ] R2：每传完一个，剩余数减 1；最后一个进行中时不再显示排队后缀。
- [ ] R3：取消后进度清空，无残留排队文案。
