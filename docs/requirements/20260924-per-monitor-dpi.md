# 副屏模糊 / 每监视器 DPI

- 状态：已实现（待副屏手测）
- 背景：主屏与副屏缩放比例不同时，窗口被系统位图拉伸，文字发虚；聊天区为 `QTextBrowser` HTML，观感更糊。
- 目标：进程声明 Per-Monitor V2 DPI 感知；换屏后重绘聊天/文件视图。
- 非目标：改气泡视觉设计；强制锁定 100% 缩放。

## 验收标准

- [ ] D1：窗口拖到另一缩放比例的显示器后，正文与聊天气泡清晰（非位图发虚）
- [ ] D2：换屏后聊天气泡与文件列表仍可读、布局正常

## 影响范围

- `src/main.cpp`
- `src/mainwindow.cpp` / `mainwindow.h`
