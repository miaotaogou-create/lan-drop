# 副屏模糊 / 每监视器 DPI

- 状态：已实现（主 125%/副 100% 待再验）
- 背景：主屏与副屏缩放比例不同时，窗口被系统位图拉伸，文字发虚；聊天区为 `QTextBrowser` HTML，观感更糊。根因还包括：气泡 PNG 用了 `qApp->devicePixelRatio()`（全机最高屏），主 125% 时副屏也按错倍率画。
- 目标：进程声明 Per-Monitor V2；分数缩放 PassThrough；按窗口当前屏 DPR 重画气泡；换屏后重绘。
- 非目标：改气泡视觉设计；强制锁定 100% 缩放。

## 验收标准

- [ ] D1：窗口拖到另一缩放比例的显示器后，正文与聊天气泡清晰（非位图发虚）
- [ ] D2：换屏后聊天气泡与文件列表仍可读、布局正常

## 影响范围

- `src/main.cpp`
- `src/mainwindow.cpp` / `mainwindow.h`
