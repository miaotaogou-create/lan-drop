# 托盘后台发送完成提示

- 状态：已实现（待手测）
- 背景：躲进托盘传大文件时，收件有 toast，发送完成往往只有提示音。
- 目标：主窗口不可见且本轮发送队列清空时，给出「发送完成」托盘摘要。
- 非目标：每个文件各弹一次；改提示音策略。

## 用户故事

作为使用者，我最小化到托盘传文件后，希望传完一眼知道，不必再打开窗口盯进度。

## 行为

1. 某次上传成功后若队列已空，且主窗口不可见：`maybeTrayNotify`「发送完成」+ 文件名（可附对端名）。
2. 窗口可见时不弹（与现有收件策略一致）。
3. 取消发送不弹完成提示。

## 验收标准

- [ ] S1：托盘隐藏时发完单文件有完成提示。
- [ ] S2：窗口前台发送完成不弹托盘条。
- [ ] S3：取消发送不出现「发送完成」。
