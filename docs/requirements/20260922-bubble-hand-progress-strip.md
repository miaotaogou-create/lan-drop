# 气泡手型与 Composer 进度并入输入卡

- 状态：已实现
- 背景：去掉文字气泡下方「复制」后，悬停仍是箭头，可复制不易发现；发送进度仍是输入卡上方第二张浮卡，像临时贴片。
- 目标：悬停可点锚点变手型；传输进度条作为输入白卡顶条，一张卡完成。
- 非目标：改复制协议；文件 Tab 进度卡大改；弹窗 token 合并（下轮）。

## 用户故事

作为使用者，我悬停文字气泡时希望光标变成手，知道能点复制；传文件时进度应像输入区的一部分，而不是再叠一张蓝卡。

## 行为

1. 悬停 `landrop://` 锚点：聊天 viewport 手型光标；离开 `unsetCursor`。
2. 悬停仍有「点击复制 / 打开…」提示；点后迷你白卡不变。
3. Composer 进度为 `#progressStrip`，嵌在 `#inputShell` 顶部，无独立阴影。
4. `#inputShell[xfer=true]` 时工具栏顶圆角收平，与顶条一体。

## 验收标准

- [x] H1：悬停普通文字气泡光标为手型
- [x] H2：离开气泡后光标恢复箭头
- [x] H3：传文件时进度在输入白卡内顶条，不再单独浮在卡外
- [x] H4：无传输时输入卡顶部无多余缝/空条
