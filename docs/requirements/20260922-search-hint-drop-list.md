# 搜索快捷键提示与复制链悬停对齐

- 状态：已实现（待手测）
- 背景：Ctrl+F 已可聚焦设备搜索，占位未写；文件卡/代码块复制链无悬停 title，与刚做的文字气泡不一致。设备列表拖放缺与聊天区同级的视觉反馈。
- 目标：搜索占位标明 Ctrl+F；文件卡与代码块复制/打开链补悬停提示；向列表拖文件时有明确遮罩引导。
- 非目标：会话内搜聊天记录；改拖放发送协议。

## 用户故事

作为使用者，我希望：知道能用 Ctrl+F 搜设备；悬停复制/打开时有提示；把文件拖到侧栏时一眼知道要落到某台设备上。

## 行为

1. 搜索框占位含 Ctrl+F 提示。
2. 文件卡「打开文件 / 打开所在目录 / 复制路径」与代码块「复制」悬停有对应 title（并走既有悬停 tooltip）。
3. 向设备列表拖入文件：侧栏出现遮罩「拖到具体设备上松手发送」；松手后遮罩消失。
