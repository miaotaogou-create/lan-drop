# 窗口置顶

- 状态：已实现（待手测）
- 背景：对照传文件时主窗口常被盖住，再点任务栏麻烦。
- 目标：设置增加「窗口置顶」开关，持久化；开启后主窗口始终在最前。
- 非目标：标题栏钉按钮动画；多显示器特殊策略。

## 用户故事

作为使用者，我希望局域快传可以钉在桌面最前，方便边传边看别的窗口。

## 行为

1. 设置增加「窗口置顶」开关，默认关；写入 `alwaysOnTop`。
2. 开启：主窗口 `WindowStaysOnTopHint`；关闭：去掉该 hint。
3. 切换时保持无边框等现有窗口标志，必要时 `show()` 使生效。
4. 启动时按 settings 应用。

## 验收标准

- [ ] A1：开启并保存后，主窗口盖在其它普通窗口之上。
- [ ] A2：关闭并保存后恢复普通层级。
- [ ] A3：重启后置顶状态保持。
