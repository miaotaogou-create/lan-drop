# 发送后清理临时 zip

- 状态：已实现（待手测）
- 背景：打包产物落在临时目录 `landrop-zip`，发完/取消后不删会占盘。
- 目标：临时 zip 在发送成功、取消或失败后删除；启动时可扫掉残留。
- 非目标：保留历史 zip 归档；改对端落盘路径。

## 用户故事

作为使用者，我多次打包发工程后不希望临时目录越堆越大。

## 行为

1. 路径位于本机临时 `landrop-zip` 目录时：上传成功 / 取消 / 失败后删除该文件。
2. 成功删除后，己方气泡若仅指向该临时路径：去掉「打开/目录」所需 path（仍保留文件名）。
3. 启动时清理该临时目录内残留 zip（可选，本轮做）。
4. 非该目录的普通文件发送不删。

## 验收标准

- [ ] C1：zip 发送成功后临时文件不在。
- [ ] C2：发送中取消后临时 zip 删除。
- [ ] C3：普通文件发送不受影响。
