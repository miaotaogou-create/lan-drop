# 开机自动启动（与托盘配套）

- 状态：已实现（待手测）
- 背景：关窗进托盘后可后台收文件，但每次开机仍要手动开应用，局域网发现断档。
- 目标：设置中增加「开机自动启动」；开启后登录系统自动拉起本程序（默认关）。
- 非目标：强制管理员权限；服务化常驻；改关窗进托盘语义。

## 用户故事

作为使用者，我希望勾选一次后，开机就能被同事发现并收文件，不必每次手动打开。

## 行为

1. 设置开关「开机自动启动」；默认关闭。
2. 保存设置时写入/清除本机登录启动项（Windows：当前用户 Run；其它平台尽力写桌面自动启动，不支持则开关仍可存配置）。
3. 启动时若配置为开：校正启动项指向当前可执行文件路径（安装目录搬迁后仍有效）。
4. 与「关闭到托盘」独立；可只开其一。
