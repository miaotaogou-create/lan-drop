# 传输进度条胶囊化

- 状态：已实现（待手测）
- 背景：聊天区气泡/系统条已有白卡胶囊感，composer 与文件 Tab 顶栏进度仍是裸蓝字，传输时视觉断层。
- 目标：进度行收入圆角白卡/浅蓝胶囊，与连接条、空态白卡同一语言；取消/清空排队仍在同行。
- 非目标：改进度文案算法；自定义进度百分比环。

## 用户故事

作为使用者，我传文件时希望顶栏进度像产品控件，而不是一行飘在输入框上的字。

## 行为

1. 有进度文案时：聊天输入区上方与文件 Tab 顶栏显示圆角胶囊底。
2. 「取消全部 / 清空排队」仍在胶囊同行右侧。
3. 无进度且无取消时整行藏起。
