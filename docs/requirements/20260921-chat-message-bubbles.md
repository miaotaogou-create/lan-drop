# 聊天消息区红框细节（对齐参考图）

- 状态：已实现
- 背景：会话顶栏与底部输入区已对齐；消息区仍是纯文本日志，与参考图红框（直连胶囊、气泡、文件卡、代码块）差距大。
- 目标：把参考图中红框标出的聊天区细节落到 Qt 客户端，可演示、可手测。
- 非目标（本轮不做）：
  - 真实 Ping / 链路类型探测（顶栏副行继续占位）
  - 文件传输 Tab 真实列表
  - 对端回执协议（「已送达」用本机请求往返时延近似）
  - 拖放进聊天区、消息编辑/撤回
  - 未完成传输的实时进度条画在气泡内（上传进度仍用 composer 上方进度条）

## 用户故事

作为使用者，我希望选中对端后，聊天区顶部是居中直连胶囊；发出的文字是右侧蓝气泡并带送达时延；收到的文件是左侧卡片（含落盘提示与打开下载目录）；代码围栏显示为深色代码块并可复制。

## 布局与行为（对照红框）

### 1. 直连胶囊（聊天区顶部居中）

- 形态：居中白底圆角胶囊（非全宽绿条），细灰边
- 左侧：绿色盾牌 + 对勾图标（`shield-check.svg`）
- 文案：`已建立局域网直连: {名称} ({IP}:{端口})`（冒号后可有空格，与参考图一致）

### 2. 发出文字气泡（右对齐）

- 右侧本机字母头像（约 40px，圆角外形，设备名首字，蓝底），与名字行**顶对齐**
- 元数据行：`我 {HH:mm:ss}` + 绿色 `✓✓ 已送达 - {n}ms`（在头像左侧、与头像顶齐）
- 气泡：蓝底白字、四角统一圆角矩形；在名字**下方**、相对头像斜对角偏下（勿把头像贴气泡底边）

### 3. 收到文字气泡（左对齐）

- 左侧对端头像（约 40px，橙底），与名字行顶对齐
- 元数据：`{对端名} {HH:mm:ss}`；在头像右侧与头像顶齐
- 气泡：白底深字、浅灰细边、圆角矩形；在名字下方、相对头像斜对角偏下

### 4. 系统/抖动

- 居中浅色胶囊：`{谁} 抖动了窗口` / 本机发出抖动的对应文案（保持现有语义）

### 5. 文件卡片（收/发）

- 白底圆角卡：文件图标、文件名、大小
- 完成后：满进度蓝条 + 绿色 `✓✓ 传输完成 (已落盘)`；速度若无实测则省略右侧速度数字
- SHA256：对本机已落盘文件计算并截断展示（如 `SHA256: 9f86d081…`）；发送侧可对源文件计算
- 操作：收文件显示「下载保存至本地」（实际打开本机已落盘路径所在目录或用系统打开文件）；旁注「局域网直传 · 已存入下载目录」
- 发文件成功后同样以卡片记入聊天流（本侧，右对齐或居中卡均可；优先右对齐简化版）

### 6. 代码块（发出或收到的 ``` 围栏）

- 若正文含 Markdown 风格 ` ```lang ` … ` ``` ` 围栏：整段渲染为深色代码块
- 顶栏：语言名（无则 `text`）+「复制」链（点后写入剪贴板）
- 非围栏正文仍走普通气泡

### 7. 顶栏（已有，本轮仅校对）

- 保持头像、名称、绿点、`IP:端口`、副行占位、双 Tab；本轮不改 Ping/链路真值

## 验收标准

- [x] M1：选中对端后，消息区上方为居中直连胶囊（白底、绿盾、文案含名称与地址）
- [x] M2：发出文字为右对齐蓝气泡，带「我 + 时间」与绿色「已送达 - Nms」（成功时）
- [x] M3：收到文字为左对齐白气泡，带对端名与时间
- [x] M4：收到文件在聊天区显示文件卡（名、大小、完成态、SHA256 截断、可打开本机文件/目录）
- [x] M5：含 ``` 围栏的消息显示深色代码块，点「复制」写入剪贴板
- [x] M6：抖动仍为居中提示，不破坏气泡流
- [x] M7：旧会话切换后历史按气泡样式重绘，不丢消息
