# 直连状态条改为参考图胶囊

- 状态：已实现
- 背景：选中对端后顶部已有「已建立局域网直连」文案，但在白底上几乎看不出胶囊轮廓；参考图为浅灰底上的白底圆角胶囊，且设备名加粗。
- 目标：与参考图一致的居中胶囊形态与字重层次。
- 非目标：改协议、改文案语义、改盾牌图标含义。

## 用户故事

作为使用者，我希望选中对端后，聊天区顶部能立刻认出「已建立局域网直连」是一枚独立胶囊，而不是一行贴在白底上的灰字。

## 验收标准

- [x] C1：胶囊宿主为浅灰底（与消息区同色系，如 `#f8fafc`），白底胶囊轮廓清晰可见
- [x] C2：胶囊为居中、非全宽；细灰边；两端接近半圆（真胶囊）
- [x] C3：左侧绿盾 + 对勾；其后文案为「已建立局域网直连：」灰字 + 设备名加粗深色 + `(IP:端口)` 灰字
- [x] C4：选中对端后，**离线时**连接条可见警示；**在线时**折叠腾出聊天区（见 `20260922-scrollbar-banner-fold.md`）

## 影响范围

- `src/mainwindow.cpp`：胶囊宿主背景、样式、文案富文本/分层
- `docs/test/mvp-cases.md`
