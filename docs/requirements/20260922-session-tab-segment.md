# 会话 Tab 改为分段控件

- 状态：已实现（待手测）
- 背景：「即时聊天」「文件传输」是两个独立蓝边按钮，与近期白卡/胶囊语言不一致，顶栏也偏挤。
- 目标：收入同一灰底槽内，选中项白底浮起，成现代分段控件。
- 非目标：改 Tab 内容与切换逻辑；加切换动画。

## 用户故事

作为使用者，我希望聊天/文件切换看起来像一个控件，而不是两个并列按钮。

## 行为

1. 两 Tab 放在同一圆角灰底容器内。
2. 当前 Tab：白底、字重更高、主色字。
3. 未选中：灰字、透明底；悬停略加深。
4. 文件数角标文案仍显示在文件 Tab 上。
