# 发送侧气泡内传输进度

- 状态：已实现（待手测）
- 背景：大文件发送时，聊天里要等传完才突然冒出「已完成」文件卡；过程中只能看输入区上方一行百分比，主路径体感差。
- 目标：开始发送后聊天区立刻出现右侧文件卡，条与文案随上传百分比更新；成功后变为现有完成态。
- 非目标：
  - 接收方气泡内实时进度（已另开 `20260922-recv-progress.md`）
  - 失败卡上的「重试」按钮（已另开 `20260922-send-fail-retry.md`）
  - 托盘图标角标、自定义铃声
  - 改上传协议或并发模型

## 用户故事

作为使用者，我希望拖进或选择文件后马上在聊天里看到发送进度，传完再变成可打开的完成卡，不必盯着输入框上方的一行字。

## 行为

1. 对当前对端开始上传时：立刻插入一条发出文件卡（进行中），文案如「发送中 N%」，进度条宽度约等于 N%（未满时不是满蓝条，也不写「传输完成」）。
2. 进度更新：约每 ≥2 个百分点或间隔约 300ms 刷新一次界面（避免狂刷 HTML 闪烁）。
3. 成功：同一条卡变为完成态——满蓝条 + `✓✓ 传输完成 (已落盘)` + SHA（若有）+「打开文件 / 打开所在目录」，与今日成功卡一致；顶栏进度文字可清空。
4. 失败：进行中卡移除（或不再显示为成功卡），保留现有居中红色「发送失败」提示；队列行为与现网一致（失败清空队列）。
5. 切换到其他对端再切回：进行中卡与当前百分比仍在该会话中，不串到别的对端。
6. 「文件传输」Tab：进行中卡同样可见；页顶 `m_fileLive` 进度文字可与气泡并存、数字不矛盾。
7. 队列多文件：每个文件各自一条卡，按现有串行队列依次从进行中→完成。

## 验收标准

- [ ] P1：开始发大文件后聊天区立刻出现右侧进行中文件卡，「发送中 N%」且条未满。
- [ ] P2：百分比随上传升高；完成后同卡变为满条 +「传输完成」+ 打开链接可用。
- [ ] P3：发送失败时无假「传输完成」卡，有失败提示。
- [ ] P4：切到另一对端再切回，进行中进度仍对应当前上传会话。
- [ ] P5：「文件传输」Tab 能看到进行中/完成后的同一条卡。
