# 聊天区 Ctrl+V 粘贴发送文件

- 状态：已实现（待手测）
- 背景：拖放发送已做；Windows 上更常「资源管理器复制 → 聊天框粘贴」。
- 目标：选中对端后，剪贴板含本地文件/文件夹时，在输入框或聊天区按 Ctrl+V 即可排队发送（规则与拖放一致）。
- 非目标：
  - 粘贴图片字节流直接当文件发（已另开 `20260922-paste-clipboard-image.md`）
  - 粘贴纯文本时改行为（仍插入输入框）
  - 递归子目录

## 用户故事

作为使用者，我希望复制文件后在聊天里 Ctrl+V 就能发出去，不必再点按钮或拖鼠标。

## 行为

1. 焦点在输入框或聊天消息区：Ctrl+V（macOS 为 Command+V，顺带支持）时，若剪贴板有本地文件/文件夹路径 → 按拖放同一套规则排队发送，并吞掉默认粘贴。
2. 剪贴板仅为文本（或无可发文件）→ 不拦截，输入框正常粘贴文字；聊天区只读则无文字粘贴。
3. 未选对端 / 正在上传：提示与拖放一致（文案可统一为「发送」而非仅「拖放」）。
4. 文件夹只取顶层文件；多文件排队。

## 验收标准

- [ ] P1：选中对端，资源管理器复制一个文件，在输入框 Ctrl+V，对端能收到。
- [ ] P2：复制含多个文件的文件夹，Ctrl+V 后顶层文件依次发送。
- [ ] P3：输入框粘贴普通文字不受影响。
- [ ] P4：未选对端时 Ctrl+V 文件有提示；拖放行为不变。
