# 默认窗口更紧凑、聊天区去掉横向滚动条

- 状态：已实现（待手测）
- 背景：默认/恢复窗口过大，占满桌面；聊天区仅少量气泡也出现横向滚动条（内容几乎与视口同宽时仍露出滚动条）。
- 目标：默认启动更适中；记忆几何不超过可用桌面；聊天/文件区不出现无意义横向滚动条。
- 非目标：改气泡视觉风格；强制用户缩小已记住的合理尺寸。

## 用户故事

作为使用者，我希望打开软件是顺手大小，聊天区只上下滚，不要莫名其妙的左右条。

## 行为

1. 无记忆几何时：默认约 `960×640`（原 1180×720）；最小约 `760×480`（原 900×560）。
2. 恢复记忆几何时：宽高钳在当前屏 `availableGeometry` 约 92% 内，避免撑满/超出。
3. 聊天与文件 `QTextBrowser`：关闭横向滚动条；按控件宽度换行。
4. 文件卡/代码块固定宽度略收，减少窄栏溢出。

## 验收标准

- [x] W1：清除窗口几何后启动，窗口明显小于整屏，约 960×640 量级。（实现已对齐，待手测）
- [x] W2：聊天仅短文字时无横向滚动条。（实现已对齐，待手测）
- [x] W3：缩小窗口后仍只有纵向滚动（或内容换行），不靠横向条阅读。（实现已对齐，待手测）
