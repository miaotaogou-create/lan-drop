# 顶栏钮对齐、复制 chip 与送达 meta

- 状态：已实现（待手测）
- 背景：顶栏「网页共享」与侧栏「+ 加 IP」同系蓝胶囊但高度不一；代码块/文字「复制」仍是小字链，与文件卡位图胶囊断层；发出消息缺「发送中」、送达标记过小。
- 目标：同系蓝钮等高；复制一律胶囊；发出路径 meta 清晰可读。
- 非目标：改复制协议；重做气泡形状；全局 focus 环。

## 用户故事

作为使用者，我希望：顶栏操作一行齐；复制按钮和文件操作同一套；发出消息立刻有「发送中」、送达后标记清楚。

## 行为

1. `#shareBtn` / `#addBtn`：统一 `padding: 6px 12px; min-height: 32px`。
2. 代码块「复制」、文字气泡「复制」：复用位图 `actionChipHtml`。
3. 发出且未确认（`rttMs < 0`）：meta 显示灰色「发送中…」徽标。
4. 送达：绿色「已送达 · Nms」徽标，替代几乎看不见的 `✓✓` 小字。
