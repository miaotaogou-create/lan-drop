# 失败重试 chip、顶栏层次、置顶钉标与编辑节点白卡

- 状态：已实现（待手测）
- 背景：文件操作已 chip 化，失败重试仍是蓝字链；标题栏/会话顶栏仍平贴；对端置顶只靠右键与副行文字；编辑手动节点仍是系统对话框。
- 目标：重试对齐 chip；顶栏加软分隔与层次；列表头像显示置顶钉；编辑节点走加 IP 同款白卡。
- 非目标：会话顶栏再加一颗置顶钮；设置/共享大改 token 对齐（下轮）。

## 用户故事

作为使用者，我希望：发送失败时重试像真正的按钮；一眼看出谁被置顶；改手动节点时弹窗和加 IP 是同一套现代白卡。

## 行为

1. 失败消息：「重试/重发」为主色 chip；「重发剩余 N」为次 chip。
2. `#titleBar` / `#peerHeader`：底部分隔略软；工具区与窗口钮之间有细竖分隔。
3. 置顶对端：列表头像左下角钉标（右键置顶仍保留）。
4. 编辑手动节点：无边框白卡+阴影，字段风格对齐加 IP。
