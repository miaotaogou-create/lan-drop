# 设置对话框（对齐参考图）

- 状态：已实现（线程池与提示音仍为配置占位）
- 背景：当前「设置」是系统原生表单（本机名称 / 传输端口 / 发现端口 / 下载目录），与参考图「局域快传设置」差距大。
- 目标：对话框**布局与文案**对齐参考图；已有字段继续可保存；新增开关与线程数按下方规则处理。
- 非目标（本轮不做）：
  - 真正的多线程并发上传池（「并发传输线程数」仅配置入库，传输逻辑仍单队列）
  - 真正的系统提示音播放（「通知声」仅配置入库）
  - 设置页内展示「发现端口」（继续用已有配置值，界面不再编辑）

## 用户故事

作为使用者，我希望在统一风格的设置弹窗里改设备名、HTTP 端口、下载目录，并开关抖动/通知偏好，保存后立即生效（端口类会重新监听）。

## 布局（对照参考图）

1. **顶栏**：深色圆角方块 + 白色齿轮；标题「局域快传设置」；副标题「设备名称、下载存储与接收提示」；右上关闭；底部分割线
2. **本机设备名称**（全宽）+ 灰色说明「局域网内其他设备将显示此设备名称」
3. **一行两列**：本地 HTTP 监听端口 | 并发传输线程数（默认 8）
4. **文件接收下载目录 (落盘路径)**（全宽）+ 说明「文件传输以 HTTP Stream 模式直接写盘，避免内存溢出」
5. **开关区**（左右：文案 | 勾选框）
   - 窗口轻颤与抖动提醒 (Nudge)
   - 新消息与传输完成通知声
6. **底栏**：仅右对齐「保存并关闭」蓝按钮

窗体：无边框圆角 + `WA_TranslucentBackground`（同加 IP 对话框，避免四角黑三角）。

## 字段映射

| 界面 | 配置键 | 行为 |
|------|--------|------|
| 本机设备名称 | `deviceName` | 保存后刷新发现身份 |
| 本地 HTTP 监听端口 | `port` | 保存后 `boot()` 重监听 |
| 并发传输线程数 | `transferThreads` | 入库，范围 1–32；本轮不改上传实现 |
| 下载目录 | `downloadDir` | 保存后应用到 HTTP 落盘 |
| （界面不展示） | `discoverPort` | 保持文件中原值 |
| Nudge | `nudgeEnabled` | 关则不发送/不响应抖动 |
| 通知声 | `soundNotification` | 入库；本轮不播声音 |
