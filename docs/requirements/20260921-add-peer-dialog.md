# 跨网段直连 / 手动添加节点对话框（对齐参考图）

- 状态：已实现（部门标签仍为界面占位）
- 背景：左侧「+ 加 IP」当前是简陋三行表单（IP / 端口 / 备注 + 确定取消），与参考图「跨网段直连」弹窗差距大。
- 目标：把对话框**布局与文案**对齐参考图，并保留「添加后探测 `/api/info`」的既有能力。
- 非目标（本轮不做）：
  - 部门 / 标签持久化进协议或设置文件
  - 真正的 ICMP Ping（仅 HTTP 探测 `/api/info`）
  - 拖拽无边框窗体、毛玻璃、动画

## 用户故事

作为使用者，当自动发现不到对端（跨 VLAN / VPN / 广播被关）时，我希望用清晰的「跨网段直连」对话框填 IP 并可选先测通，再添加连接。

## 布局（对照参考图）

1. **顶栏**
   - 左：蓝底圆角方块 + 白色地球/网络图标
   - 中：标题「跨网段直连 / 手动添加节点」；副标题「当设备处于不同 VLAN、VPN 或禁用了 mDNS 广播时使用」
   - 右：关闭（×）
   - 底部分割线
2. **表单**
   - 一行：目标 IP 地址（约 2/3） | 服务端口（约 1/3，默认 `8848`）
   - 一行：设备别名（全宽）
   - 一行：系统类型（下拉） | 部门 / 标签（文本，本轮仅界面）
   - 链接行：闪电图标 + 「测试目标端口连通性 (Ping /api/info)」，旁侧可显示探测结果短文案
3. **底栏**
   - 顶部分割线
   - 右对齐：「取消」描边按钮；「+ 添加并连接」蓝底主按钮

## 系统类型选项 → `os` 字段

| 下拉文案 | 写入 `os`（影响头像） |
|---------|----------------------|
| Windows PC | `windows` |
| Linux (Ubuntu / 麒麟) | `linux` |
| ARM64 Linux (工控/树莓派) | `arm-linux` |
| iOS / Android 手机 | `ios` |

探测成功后若 `/api/info` 带回 `os`，以对端回报为准覆盖。

## 交互

- 「测试…」：对当前填写的 IP:端口发 `GET /api/info`，成功显示连通（可含耗时），失败显示原因；**不**因此自动关闭对话框。
- 「添加并连接」：校验 IP/端口 → `addManual`（别名 + 所选系统类型）→ 刷新列表并选中该节点 → 再探测一次 `/api/info` → 关闭对话框。
- 「取消」/ ×：关闭，不写入。
- 「部门 / 标签」：本轮可填写但不入库。

## 验收标准

- [x] D1：点「+ 加 IP」弹出对话框，标题与副标题、顶栏图标与参考图一致
- [x] D2：可见 IP | 端口、别名、系统类型 | 部门标签、测试连通链接、取消 / 添加并连接
- [x] D3：端口默认 `8848`；IP 或端口无效时有提示且不添加
- [x] D4：点测试连通，对可达本机（如 `127.0.0.1` 本进程）能显示成功类文案
- [x] D5：添加成功后列表出现该节点；所选系统类型对应头像（直至探测回报覆盖）
- [x] D6：部门标签本轮不要求出现在列表或设置文件中
