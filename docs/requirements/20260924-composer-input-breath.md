# 聊天输入卡：字体、留白与去腰斩线

- 状态：已实现（待手测）
- 背景：占位符中英粗细不一、贴左上角；工具栏与输入区硬横线像腰斩；字号偏小发虚。
- 目标：雅黑 UI + 抗锯齿；14px / 深板岩字色与铅灰占位符；加大内边距；去掉工具栏底部分隔线，靠留白分区。
- 非目标：改发送逻辑；把发送钮改成悬浮叠字；重做工具三钮图标。

## 用户故事

作为使用者，我希望输入区像微信/飞书一样通透：字清晰、有呼吸、工具与输入同属一张卡。

## 行为

1. 输入框显式选用 `Microsoft YaHei UI`（或回退雅黑/Segoe），`PreferAntialias`，约 14px。
2. 正文色 `#1E293B`，占位符 `#94A3B8`（调色板，兼容 QPlainTextEdit）。
3. 输入区内边距约左 14 / 上 10；工具栏无 `border-bottom`。
4. 整卡仍为 `#inputShell` 白底圆角 + 聚焦蓝边。
