# 托盘收件提示点击跳转对端

- 状态：已实现（待手测）
- 背景：后台收件已有右下角提示，但点击只恢复窗口，用户还要在左侧列表里自己找发送方，费一步。
- 目标：点击收件提示（或系统气泡）时，恢复窗口并自动选中该发送方、打开即时聊天并滚到最新。
- 非目标：
  - 未读角标 / 多条通知队列
  - 仅点托盘图标时强制切会话（图标单击仍只恢复窗口，保持当前选中）

## 用户故事

作为使用者，我希望点一下「谁发了什么」的提示，就能直接进到对方的聊天会话，马上回消息或看文件。

## 行为

1. 后台弹出收件提示时，记住该条对应的对端 `ip:port`。
2. 点击自绘提示 → 恢复主窗口 + 选中该对端 + 切到「即时聊天」+ 聊天滚到最新。
3. 若系统 `messageClicked` 可用，行为同 2。
4. 单击/双击托盘图标、菜单「显示主窗口」→ 仅恢复窗口，不改当前选中对端。
5. 首次进托盘提示（「已在托盘运行…」）点击 → 仅恢复，不跳会话。
6. 对端已从列表消失时：仍恢复窗口，无法选中则保持原选中。

## 验收标准

- [ ] J1：托盘收文字提示，点击后窗口恢复且列表选中该发送方，聊天为最新消息。
- [ ] J2：托盘收文件提示，点击后同上并可见文件卡。
- [ ] J3：仅点托盘图标恢复时，选中对端不变。
- [ ] J4：首次「已在托盘运行」提示点击不强制切会话。
