## 用户故事

作为使用者，我希望：打字区一眼是主操作面；顶栏不挤；传文件时进度条和离线条也有一点「浮」的层次，而不是贴在底板上。

## 行为

1. `#inputShell` 应用与空卡同参轻阴影；圆角略加大；聚焦仍保留蓝描边。
2. 会话顶栏下载：仅图标 + tooltip「打开本机文件接收目录」，无「下载目录」文案。
3. `#connBanner`、`#progressCapsule` 应用同参轻阴影。
4. 侧栏右侧极淡边线，与灰会话区软分隔。
