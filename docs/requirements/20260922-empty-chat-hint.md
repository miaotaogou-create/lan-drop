# 空会话轻提示

- 状态：已实现（待手测）
- 背景：选中对端后若还没聊过，聊天区几乎空白，新用户不一定知道可打字或拖文件。
- 目标：尚无文字/文件往来时，居中一句轻提示引导操作。
- 非目标：插图引导页、动画、改拖放逻辑。

## 用户故事

作为使用者，我第一次点开某台设备时，希望一眼知道「在这发消息或拖文件」。

## 行为

1. 当前会话记录里还没有文字气泡、文件卡时（可有直连系统条）：聊天区显示居中浅色提示，如「发消息，或把文件拖到这里」。
2. 一旦有文字或文件往来：提示不再出现。
3. 文件传输 Tab 空态保持既有「还没有与该对端的文件传输」文案。

## 验收标准

- [x] E1：新选对端、尚无聊天往来时可见引导句（实现已对齐，待手测）
- [x] E2：发出或收到一条文字/文件后引导消失（实现已对齐，待手测）
