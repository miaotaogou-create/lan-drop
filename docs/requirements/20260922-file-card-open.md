# 文件卡直接打开文件

- 状态：已实现（待手测）
- 背景：文件卡链接 `landrop://reveal/` 只打开父目录，收完还要再点一次文件；参考图主操作是打开/保存到本地，本机已落盘时应优先打开文件本身。
- 目标：文件卡提供「打开文件」为主操作，并保留「打开所在目录」。
- 非目标：
  - 未落盘时的真实二次下载（本机路径已存在）
  - 用系统「在资源管理器中显示并选中」的专用 API（打开目录即可）

## 用户故事

作为使用者，我希望点一下文件卡就能用默认程序打开刚收到的文件，不必先开文件夹再找。

## 行为

1. 文件卡有本机路径时：
   - 主链接「打开文件」→ 用系统默认程序打开该文件。
   - 次链接「打开所在目录」→ 打开父目录（原 reveal 行为）。
2. 路径不存在：提示或静默忽略（与现有一致，不强弹框亦可）。
3. 发出侧文件卡同样两条链接（打开源文件 / 打开目录）。
4. 旁注仍可保留「局域网直传 · 已存入下载目录」（收件）或省略（发件）。

## 验收标准

- [ ] F1：收到文件后点「打开文件」，系统用默认程序打开该文件。
- [ ] F2：点「打开所在目录」，资源管理器打开下载目录（父路径）。
- [ ] F3：发出的文件卡「打开文件」可打开本机源文件。
- [ ] F4：无路径时不显示无效链接。
