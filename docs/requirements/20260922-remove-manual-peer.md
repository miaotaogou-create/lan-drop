# 手动节点可从列表删除

- 状态：已实现
- 背景：手动节点已持久化；错填或过期的 IP 会一直留在列表，目前只能手改 `settings.json`。
- 目标：用户可在设备列表删除手动节点，并同步写回设置；自动发现的节点不可用此方式删除。
- 非目标：
  - 编辑别名 / 改端口（别名/标签编辑见 `20260922-edit-manual-peer.md`；改端口另开）
  - 删除自动发现节点
  - 部门标签（见 `20260922-peer-tag.md`）

## 用户故事

作为跨网段用户，我希望能删掉不再需要或加错的手动节点，以免列表越积越乱，重启后又冒出来。

## 行为

1. 仅对 `manual` 节点提供删除入口（右键菜单「删除手动节点」，并支持 Delete 键）。
2. 删除前简短确认；确认后从内存列表移除，并调用既有持久化写回 `manualPeers`。
3. 非手动节点：菜单项禁用；按 Delete 提示不可删。
4. 删除后若当前会话正选中该节点，会话区回到空状态。

## 验收标准

- [x] R1：手动节点右键可见「删除手动节点」；确认后列表消失
- [x] R2：删除后 `settings.json` 的 `manualPeers` 不再含该项；重启后也不再出现
- [x] R3：自动发现节点不能通过该入口删除
- [x] R4：`--self-check` 覆盖 `addManual` → `removeManual` 后列表无该项
