# 气泡「复制」链接可读性

- 状态：已实现（待手测）
- 背景：文字气泡下方「复制」字过浅、过小，浅灰底上几乎看不清。
- 目标：「复制」一眼能认出来、像可点链接。
- 非目标：改复制行为或反馈文案。

## 用户故事

作为使用者，我希望气泡下的「复制」清楚可见，不用凑近找。

## 行为

1. 普通文字气泡下的「复制」：字号上调，颜色改为可辨认的链接蓝（与「打开文件」同档），不再用过浅灰。
2. 点击复制、已复制提示等行为不变。
