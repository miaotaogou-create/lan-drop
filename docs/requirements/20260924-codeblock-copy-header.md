# 代码块顶栏复制与围栏识别

- 状态：已实现（待手测）
- 背景：代码围栏气泡的「复制」落在深色卡下方，与参考图顶栏位置不符；从别处粘贴的 ` ```cpp ` 围栏偶发未识别，整段走成普通蓝气泡。
- 目标：「复制」在深色卡顶栏右侧；点卡即可复制；围栏识别更稳；注释行浅色区分。
- 非目标：完整语法高亮引擎；改普通文字气泡复制。

## 验收

- [ ] C1：` ```bash ` 围栏消息：「复制」在顶栏右侧（不在卡下）。
- [ ] C2：点深色卡任意处可复制正文。
- [ ] C3：` ```cpp ` 围栏同样出深色代码卡（非整段蓝气泡）。
- [ ] C4：以 `#` / `//` 开头的行呈灰色注释色。
