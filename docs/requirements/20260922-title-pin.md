# 标题栏一键置顶

- 状态：已实现（待手测）
- 背景：对照传文件时常被盖住，进设置开置顶太绕。
- 目标：顶栏增加置顶开关，热切并持久化（复用 `alwaysOnTop`）。
- 非目标：动画钉、多显示器特殊策略。

## 用户故事

作为使用者，我传大文件时希望一点标题栏就能钉在最前。

## 行为

1. 标题栏（设置旁）增加可点的置顶按钮，勾选态表示当前置顶。
2. 切换后立即 `applyAlwaysOnTop`，并写入 settings。
3. 打开设置时开关与按钮状态一致。

## 验收标准

- [ ] P1：点置顶后主窗口盖在普通窗口上。
- [ ] P2：再点取消置顶。
- [ ] P3：重启后状态保持。
