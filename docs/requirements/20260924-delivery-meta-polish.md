# 发出消息 meta：耗时人性化与送达胶囊质感

- 状态：已实现（待手测）
- 背景：发出气泡「已送达 · 37371ms」像未格式化调试值；时间字发虚；绿胶囊边过亮；胶囊内中英垂直错位。
- 目标：耗时可读（ms / s / m s）；时间 11px 次级灰且抗锯齿；薄荷绿胶囊温润；中英同轴。
- 非目标：改 RTT 探测逻辑；改「发送中…」「发送失败」语义。

## 行为

1. `formatDurationMs`：`<1ms`；`<1000` → `Nms`；`<60000` → `N.Ns`；否则 `Nm Ns`。
2. 送达胶囊文案：`已送达 · {formatDurationMs}`；底 `#ecfdf5`、字 `#059669`、边 `#a7f3d0`。
3. 时间：位图绘制，优先 Segoe UI / Consolas，11px，`#94a3b8`，`PreferAntialias`。
4. 胶囊文字：雅黑 UI + 基线居中，避免中英高低错位。

## 验收

- [ ] D1：37371ms 显示为 `37.4s`（非五位毫秒）。
- [ ] D2：850ms 仍为 `850ms`；65s 为 `1m 5s` 类。
- [ ] D3：时间字色为次级灰，无明显发虚。
- [ ] D4：送达胶囊无荧光绿硬边感；「已送达」与时长垂直同轴。
