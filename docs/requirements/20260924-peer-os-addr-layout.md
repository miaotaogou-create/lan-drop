# 侧栏 OS 截断与会话顶栏地址位置

- 状态：已确认
- 背景：侧栏副行把 `linux` 截成 `linu`；会话顶栏右侧 IP:端口药丸占位别扭，且与「一眼看名字」冲突。
- 目标：OS 显示完整短标签（放不下则整段不显示，不半截字）；顶栏地址改到名称下方副行，右侧只留 Tab 等操作。
- 非目标：改发现协议字段；去掉复制地址能力。

## 验收

- [x] O1：Linux 对端侧栏可见完整 `Linux`（或因过窄而不显示 OS），不再出现 `linu`。
- [x] O2：会话顶栏名称下方可见 `IP:端口`，可点复制；右侧无地址药丸。
- [x] O3：窄窗名称仍可省略，地址 tooltip 含全文。
