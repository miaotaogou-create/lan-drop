# 侧栏设备行文字重叠与头像裁切

- 状态：已实现
- 背景：设备行用 itemWidget 画头像与副行，但 QListWidgetItem 仍写入搜索用明文并被样式绘制；半透明行底导致「名称 / IP / OS」与自定义控件叠成一团。同时 `::item` 上下 padding 过大，44px 头像被裁切。
- 目标：仅显示 itemWidget；搜索仍可用；头像与副行完整可见、不重叠。
- 非目标：改发现协议；重做侧栏信息架构。

## 用户故事

作为使用者，我希望侧栏每一行能看清设备名、头像和状态，而不是字挤在一起、头像缺一块。

## 行为

1. 列表项不绘制可见文本；搜索关键字存数据角色，过滤逻辑不变。
2. 行内边距与行高匹配 44px 头像，头像与置顶角标完整可见。
3. 选中/悬停白卡蓝边样式保持。

## 验收标准

- [x] R1：选中设备行只见头像 + 名称 + 副行，无叠字
- [x] R2：头像四角（含系统角标/置顶钉）不被卡片裁切
- [x] R3：按名称 / IP / 标签搜索仍能过滤
