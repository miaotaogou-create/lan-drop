# 侧栏搜索框与设备行左右对齐

- 状态：已实现（待手测）；设备行描边策略见 `20260924-peer-card-white-states.md`（白卡三态，已取代「平时无边框」）
- 背景：搜索胶囊与设备卡左右边不齐、圆角不一。
- 目标：同栏左右边距咬死对齐；搜索保留唯一输入框；设备行圆角与搜索同为 10px。
- 非目标：改发现/排序逻辑；重做头像。

## 用户故事

作为使用者，我希望侧栏上下边缘齐整，设备列表干净。

## 行为

1. 侧栏左右外边距统一 12px；搜索壳高 32px、圆角 10px。
2. `QListWidget` 无 frame、无 spacing 内缩；`padding: 0`。
3. 设备行圆角 10px、底边距 6px；默认/悬停/选中配色见白卡三态需求。
