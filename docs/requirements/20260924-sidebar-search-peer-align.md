# 侧栏搜索框与设备行左右对齐

- 状态：已实现（待手测）
- 背景：搜索胶囊与设备卡左右边不齐、圆角不一；设备卡硬边框与搜索框叠成「框套框」。
- 目标：同栏左右边距咬死对齐；搜索保留唯一输入框；设备行平时无边框，悬停淡灰、选中浅蓝底，圆角与搜索同为 10px。
- 非目标：改发现/排序逻辑；重做头像。

## 用户故事

作为使用者，我希望侧栏上下边缘齐整，设备列表干净，不一眼看见两层框打架。

## 行为

1. 侧栏左右外边距统一 12px；搜索壳高 32px、圆角 10px。
2. `QListWidget` 无 frame、无 spacing 内缩；`padding: 0`。
3. `::item`：默认透明无边；`:hover` `#F1F5F9`；`:selected` `#EFF6FF`；圆角 10px；底边距 6px。
