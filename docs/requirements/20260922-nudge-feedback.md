# 抖动发送即时反馈

- 状态：已实现（待手测）
- 背景：点「抖动窗口」后要等 HTTP 回来才有系统条，中间像没点上；离线时也缺少与发文字一致的轻提示时机。
- 目标：一点就有「正在发送抖动」类反馈；成功/失败仍走现有系统条与失败条；离线走既有轻提示。
- 非目标：抖动动画改样式；改协议字段。

## 用户故事

作为使用者，我点抖动后希望马上知道已经发出去了，而不是干等。

## 行为

1. 点「抖动窗口」且已选对端：立刻顶栏进度或等价短提示「正在发送抖动…」。
2. 若对端显示离线：先走 `20260922-offline-send-hint.md` 的一次轻提示（与发文字一致）。
3. 成功：进度清空；系统条「已发送窗口抖动」；本机窗口仍轻抖。
4. 失败：进度清空；既有失败条。
5. 未选对端 / 设置关闭抖动：行为与现网一致（无发或不发）。

## 验收标准
