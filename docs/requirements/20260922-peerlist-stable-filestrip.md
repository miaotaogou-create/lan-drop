# 列表刷新去闪与文件进度顶条对齐

- 状态：已实现
- 背景：侧栏每秒 `clear`+重建 itemWidget，易闪、选中抖动；文件 Tab 进度仍是独立浮卡，与 Composer 已并入的顶条两套皮。
- 目标：对端签名未变则跳过重建，只做过滤/空态；文件页进度改为同系 `#progressStrip`、无独立阴影。
- 非目标：改发现协议；虚拟列表；文件 Tab 大改版。

## 用户故事

作为使用者，我希望左侧列表安静、不每秒闪一下；切到文件传输时进度条和聊天输入区是同一套语言。

## 行为

1. `m_peerListSig`：签名未变跳过 `clear`/重建。
2. 文件 Tab：`#progressStrip`（圆角蓝条），去掉浮卡阴影；顺带修复内层曾被 hide 导致看不见的问题。

## 验收标准

- [x] L1：静置侧栏无明显整表闪烁
- [x] L2：上/下线或未读变化仍更新
- [x] L3：文件 Tab 传文件时为顶条样式
- [x] L4：无传输时顶部无空条
