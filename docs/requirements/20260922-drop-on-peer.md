# 拖到设备列表即可发送

- 状态：已实现（待手测）
- 背景：拖放只在当前会话聊天区生效；飞秋习惯是拖到对端人名上就发。
- 目标：拖文件到左侧设备列表某行，自动切到该对端并入发送队列。
- 非目标：拖到空白处自动选「最近对端」；跨窗口拖文件夹协议变更。

## 用户故事

作为使用者，我希望把文件拖到某台设备上就能发出，少点一次列表。

## 行为

1. 设备列表接受文件/文件夹拖放（规则与聊天区一致：本地路径、顶层文件夹策略不变）。
2. 松手落在某一行：选中该对端，再 `enqueueDroppedPaths`。
3. 拖入过程中可高亮当前悬停行（选中预览即可）。
4. 未落在任何行：不发送，进度区或轻提示「请拖到具体设备上」。
5. 聊天区拖放行为保持不变。

## 验收标准

- [ ] D1：拖文件到未选中的在线设备行，松手后切到该会话并开始/排队发送。
- [ ] D2：拖到列表空白处不发送，有提示。
- [ ] D3：聊天区拖放仍可发到当前会话。
