# 对端上线 / 离线切换轻提示

- 状态：已实现（待手测）
- 背景：已有离线胶囊与「发时轻提示」；对方从离线恢复在线时顶栏变绿但聊天区无声，用户常不知道可以重试。
- 目标：当前会话对端在线状态变化时，插入一条系统提示。
- 非目标：全列表所有设备刷屏；托盘气泡；自动重发失败消息。

## 用户故事

作为使用者，我盯着某台设备的会话时，希望对方重新上线能立刻在聊天区看到提示，好接着传文件或点重试。

## 行为

1. 仅针对**当前选中**对端；首次见到只记状态，不发提示。
2. 离线 → 在线：系统条「对方已重新上线，可以继续发送。」；并清除该对端的离线发送已提示标记，便于下次再离线时再提示一次。
3. 在线 → 离线：系统条「对方已离线。」
4. 不改变顶栏胶囊与离线发时提示的既有逻辑。

## 验收标准

- [x] U1：当前会话对端从离线变在线，聊天区出现上线系统条（实现已对齐，待手测）
- [x] U2：从在线变离线，出现离线系统条（实现已对齐，待手测）
- [x] U3：刚打开会话、首次见到该对端状态时不误报「上线/离线」（实现已对齐，待手测）
