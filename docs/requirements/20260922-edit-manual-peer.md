# 右键编辑手动节点别名与标签

- 状态：已实现（待手测）
- 背景：手动节点别名/部门标签只能在添加时填写；填错或业务变更只能删了再建，聊天记录 key 虽仍在但列表展示对不上。
- 目标：对手动节点右键「编辑…」，可改别名、部门标签、系统类型；IP/端口不变；立即写回 `settings.json`。
- 非目标：
  - 改 IP / 端口（会换会话 key，易丢记录，另开）
  - 自动发现节点的编辑
  - 自定义铃声

## 用户故事

作为跨网段使用者，我希望改一下某台工控机的备注或部门标签，而不必删掉重加。

## 行为

1. 手动节点右键菜单增加「编辑别名 / 标签…」（自动发现节点该项禁用或隐藏）。
2. 弹窗预填当前别名、标签、系统类型；确认后 `addManual` 覆盖同地址条目并 `persistManualPeers`。
3. 取消不改动。
4. 列表与会话顶栏立刻刷新展示。

## 验收标准

- [ ] E1：手动节点右键可见「编辑别名 / 标签…」，打开后字段为当前值。
- [ ] E2：改别名/标签保存后列表与顶栏更新，`settings.json` 同步。
- [ ] E3：退出再开仍是新值。
- [ ] E4：自动发现节点无此编辑入口（或禁用）。
- [ ] E5：`--self-check` 覆盖同地址再次 `addManual` 可覆盖 tag。
