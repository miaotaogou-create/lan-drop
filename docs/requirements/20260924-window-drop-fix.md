# 整窗拖放发送修复

- 状态：实现中
- 背景：代码已有聊天区/列表拖放，但 `QTextBrowser`/`QPlainTextEdit` 的 viewport 默认 `acceptDrops`，抢走 Explorer 拖入事件，体感为「不能拖进来」。
- 目标：从资源管理器拖文件/文件夹进主窗口任意内容区即可发送（已选对端发当前会话；拖到设备行则先选中再发）。
- 非目标：改上传协议；网页共享弹窗拖放逻辑另计；窗口外拖放。

## 用户故事

作为使用者，我希望像飞秋一样把文件拖进窗口就能发出去，而不是只能点按钮。

## 行为

1. 主窗口统一接受本地文件/文件夹 URL 拖放。
2. 拖到设备列表某行：选中该设备；松手发送。拖到列表空白处：提示对准设备，不发送。
3. 拖到右侧会话区（含输入区、文件 Tab、未选对端空态）：发往当前选中设备；未选则提示先选设备。
4. 嵌套文件夹仍弹出 zip / 仅顶层 / 取消。
5. 拖入时保留虚线高亮反馈。

## 验收标准

- [ ] D1：选中对端后，从资源管理器拖文件到聊天区/输入区，对端能收到
- [ ] D2：拖到设备列表某一行，自动选中该设备并发送
- [ ] D3：拖到列表空白处有提示且不误发
- [ ] D4：未选对端时拖到右侧有提示
- [ ] D5：嵌套文件夹拖入仍可 zip
