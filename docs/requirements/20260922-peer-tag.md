# 手动节点部门 / 标签入库

- 状态：已实现（待手测）
- 背景：加 IP 对话框已有「部门 / 标签」输入框，但确定时丢弃；跨网段多台设备时只靠别名易混。
- 目标：把标签写入 `settings.json` 的 `manualPeers`，启动恢复；侧栏与会话顶栏能看到。
- 非目标：
  - 自动发现节点打标签
  - 标签云 / 多标签筛选 UI
  - 改发现协议
  - 自定义铃声

## 用户故事

作为跨网段使用者，我希望给手动节点标上「工控 / 财务」一类标签，重启后仍在，列表里一眼能分清。

## 行为

1. 「+ 添加并连接」：若填写了部门 / 标签，一并交给 `addManual` 并写入 `manualPeers[].tag`。
2. 空标签：不写 `tag` 字段（或省略），行为与现网一致。
3. 启动恢复：读回 `tag` 后列表第二行或会话元信息可见（有值才显示）。
4. 左侧搜索：关键字可匹配标签。
5. 重新添加同 IP:端口：以本次填写覆盖标签（含清空）。

## 验收标准

- [ ] T1：添加时填标签 → `settings.json` 对应项有 `tag`。
- [ ] T2：退出再开，列表或会话顶栏仍能看到该标签。
- [ ] T3：不填标签仍可添加；旧配置无 `tag` 字段可正常启动。
- [ ] T4：搜索框输入标签关键字能筛出该节点。
- [ ] T5：`--self-check` 覆盖 tag 读写往返。
