# 最小化也可进托盘

- 状态：已实现（待手测）
- 背景：✕ 可进托盘收件，但标题栏最小化进任务栏；托盘工具用户常以为最小化=后台收件。
- 目标：当「关闭进托盘」开启且托盘可用时，最小化与 ✕ 走同一隐藏到托盘路径。
- 非目标：无托盘环境的特殊 UI；系统任务栏「钉住」行为。

## 用户故事

作为使用者，我点最小化也希望程序躲到托盘继续收文件，不必再找任务栏小窗。

## 行为

1. `closeToTray` 勾选且托盘可用：标题栏最小化 → 隐藏到托盘（与关窗同路径，含首次提示逻辑可共用）。
2. `closeToTray` 取消：最小化仍 `showMinimized()` 进任务栏。
3. 设置文案可略提「关闭/最小化到托盘」，避免只写「关闭」。
4. 托盘「打开」仍可恢复窗口。

## 验收标准

- [ ] T1：默认 closeToTray 时点最小化，窗口消失、托盘在、进程仍在。
- [ ] T2：取消 closeToTray 后最小化进任务栏。
- [ ] T3：托盘单击可恢复窗口。
