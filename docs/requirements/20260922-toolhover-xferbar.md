# 工具钮 hover、发送阴影、搜索清除与进度细条

- 状态：已实现（待手测）
- 背景：Composer 工具钮白底上 hover 仍白、几乎无反馈；发送 FAB 单独阴影被裁切；搜索 × 是系统灰块；进度胶囊只有字没有细条。
- 目标：工具悬停可见；发送钮清爽无叠影；搜索清除同系；传输胶囊内有细蓝进度条。
- 非目标：改传输协议；文件 Tab 再加数量胶囊。

## 用户故事

作为使用者，我希望：点附件前悬停有反馈；发送钮边缘干净；搜索清除好看；传文件时顶栏胶囊能看见进度在走。

## 行为

1. `#toolBtn:hover` 改为浅蓝底。
2. 去掉发送 FAB 单独阴影；输入区右下略增内边距。
3. `#search` 内清除钮：透明底、圆角 hover。
4. 聊天区与文件 Tab 进度胶囊内 4px 细进度条，由 pct 驱动；pct&lt;0 为不确定态。
