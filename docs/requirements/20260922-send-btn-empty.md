# 空内容时发送钮灰显

- 状态：已实现（待手测）
- 背景：输入框空着时发送钮仍高亮可点，点了没反应，像坏了。
- 目标：无正文时发送钮灰显不可点；有字后恢复可点。
- 非目标：改 Enter 行为（空内容仍不发送）；改图标。

## 用户故事

作为使用者，我希望没空字时发送钮看起来就点不了，有字才亮起来。

## 行为

1. 已选对端且输入框去空白后非空：发送钮可用（现网浅蓝可点）。
2. 未选对端，或输入为空/仅空白：发送钮禁用并降低对比度。
3. 输入变化时即时刷新；选中/取消对端时同步。

## 验收标准

- [x] S1：空输入时发送钮灰、点不动（实现已对齐，待手测）
- [x] S2：打字后发送钮恢复可点，Enter 仍可发（实现已对齐，待手测）
- [x] S3：未选对端时发送钮不可用（实现已对齐，待手测）
