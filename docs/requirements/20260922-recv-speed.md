# 接收进度与速率

- 状态：已实现（待手测）
- 背景：发送进度已有百分比与速率；收大文件时进度区空白，只能看气泡百分比。
- 目标：本机未在发送时，接收进行中在进度区显示「正在接收 文件 百分比 · 速率」。
- 非目标：接收中途取消写盘；本机正在发送时抢占进度区（发送优先）。

## 用户故事

作为使用者，我收大文件时也想在输入区上方看到进度和大概速度。

## 行为

1. 开始接收且 `!m_uploading`：进度区显示正在接收与百分比。
2. 进度回调估算速率（与发送同量级），显示 `xx/s`。
3. 接收完成或失败：若未在发送，清空进度区。
4. 本机正在发送：进度区仍只反映发送，不改接收文案。

## 验收标准

- [ ] R1：对端发来较大文件时，本机进度区出现「正在接收」与百分比。
- [ ] R2：传输中出现大致 `xx/s`。
- [ ] R3：收完后进度区清空（本机未发送时）。
- [ ] R4：本机发送中同时有人发来文件时，进度区仍以发送为准。
