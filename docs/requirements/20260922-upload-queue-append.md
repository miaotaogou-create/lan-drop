# 发送中自动加入队列

- 状态：已实现（待手测）
- 背景：上传中再选文件/拖放只会提示稍候，用户还得盯着传完再操作；队列能力已有，只是忙时未接入。
- 目标：发送进行中时，再选文件、拖放/粘贴、点失败重试，把新路径追加进发送队列；当前传输不中断，传完自动续传。
- 非目标：
  - 取消队列 / 调整队列顺序 UI
  - 失败后自动重试整队（失败仍清空队列，与现网一致）
  - 真多线程并发上传

## 用户故事

作为使用者，我传一个大文件时还能继续往里丢几个小文件，希望它们自动排队，不用干等。

## 行为

1. `m_uploading` 时：发送文件、发送文件夹（确认后）、拖放/粘贴、失败「重试」→ 追加到 `m_uploadQueue`（去重），系统条提示「已加入发送队列（N 个，排队共 M 个）」。
2. 不中断当前上传；当前成功结束后继续 `pumpUploadQueue`（含原先空闲时启的单文件发送）。
3. 若文件已在队列中：进度区轻提示「已在发送队列中」，不再重复入队。
4. 空闲时行为与现网一致（可开始新传；多文件仍先提示开始发送）。
5. 发送失败：仍清空剩余队列（与现网一致，本轮不改）。

## 验收标准

- [ ] Q1：发大文件过程中再拖入 2 个文件，系统条显示已入队；大文件传完后自动续传这两个。
- [ ] Q2：发送中再点「发送文件」选一个文件，同样入队并续传。
- [ ] Q3：发送中点失败重试，路径入队；不弹模态。
- [ ] Q4：重复拖入同一路径不重复排队。
- [ ] Q5：某次发送失败后，剩余队列仍被清空（与现网一致）。
