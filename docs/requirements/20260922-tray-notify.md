# 后台收件托盘气泡提示

- 状态：已实现
- 背景：关窗进托盘后仅有通知声，看不到「谁发了什么」；首次隐藏提示与收件无关。
- 目标：主窗口不可见时，收到文字或文件弹出托盘气泡摘要；点击可恢复窗口。
- 非目标：
  - 自定义铃声 / 气泡内进度
  - 前台可见时再弹气泡（避免与聊天区重复）
  - 未读角标与强制切会话

## 用户故事

作为使用者，我希望软件在托盘后台时，仍能一眼看到新消息或新文件是谁发来的，并可点气泡回到主窗口。

## 行为

1. 主窗口隐藏（托盘）时：收到普通文字 → 气泡标题含发送方，正文为截断预览。
2. 同上：收到文件 → 气泡含发送方、文件名与大小。
3. 抖动消息（`__landrop_nudge__`）不弹收件气泡（仍可抖动若窗口可见策略不变）。
4. 主窗口可见时不弹收件气泡。
5. 与通知声开关独立：关声音仍可有气泡。
6. 点击托盘气泡 → 显示并前置主窗口（同「显示主窗口」）。

## 验收标准

- [x] N1：关窗进托盘后，对端发文字出现托盘气泡（含发送方与预览）
- [x] N2：对端发文件出现托盘气泡（含文件名）
- [x] N3：主窗口在前台时收件不弹收件气泡
- [x] N4：点击气泡可恢复主窗口
