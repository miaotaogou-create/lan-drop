# 后台收件托盘气泡提示

- 状态：已实现（自绘右下角提示，待手测）
- 背景：关窗进托盘后仅有通知声，看不到「谁发了什么」。根因：`QSystemTrayIcon::showMessage` 在 Windows 10/11（专注助手/通知策略）及部分 Linux 桌面常被静默吞掉，首次进托盘提示同样可能不出现。
- 目标：主窗口不可见时，收到文字或文件弹出**可靠可见**的摘要提示（不依赖系统气泡）；点击可恢复窗口。
- 非目标：
  - 自定义铃声 / 气泡内进度
  - 前台可见时再弹提示（避免与聊天区重复）
  - 未读角标与强制切会话

## 用户故事

作为使用者，我希望软件在托盘后台时，仍能一眼看到新消息或新文件是谁发来的，并可点提示回到主窗口。

## 行为

1. 主窗口隐藏（托盘）时：收到普通文字 → 右下角自绘提示，标题含发送方，正文为截断预览。
2. 同上：收到文件 → 提示含发送方、文件名与大小。
3. 抖动消息（`__landrop_nudge__`）不弹收件提示（仍可抖动若窗口可见策略不变）。
4. 主窗口可见时不弹收件提示。
5. 与通知声开关独立：关声音仍可有提示。
6. 点击收件提示 → 显示并前置主窗口，并跳到该发送方会话（见 `20260922-tray-jump-peer.md`）。
7. 系统 `showMessage` 仅作尽力而为（可与自绘并存或省略）；验收以自绘提示为准。

## 验收标准

- [ ] N1：关窗进托盘后，对端发文字出现右下角提示（含发送方与预览）
- [ ] N2：对端发文件出现提示（含文件名）
- [ ] N3：主窗口在前台时收件不弹收件提示
- [ ] N4：点击提示可恢复主窗口
- [ ] N5：即使系统通知被关闭/专注助手开启，自绘提示仍可见
