# 侧栏选中态、空态白卡与操作胶囊统一

- 状态：已实现（待手测）
- 背景：侧栏选中行与默认同白底，悬停反而更抢眼；侧栏「暂无设备」仍是灰字，与右侧空卡断层；文件卡/失败条 action 仍是 HTML table；进度区「取消全部 / 清空排队」像文字链。
- 目标：选中一眼浅蓝卡；侧栏空态白卡引导；文件与失败操作位图胶囊；进度操作同族 chip。
- 非目标：全局键盘 focus 环大改；侧栏副行去掉在线文案；重做右侧空卡。

## 用户故事

作为使用者，我希望：左侧当前设备清晰可辨；没设备时也有同款引导卡；文件下方操作钮与卡面同现代感；传文件时取消/清空像正式按钮。

## 行为

1. `#peerList::item:selected`：浅蓝底 `#eff6ff` + 左蓝条；悬停未选中仍为浅灰，不得强过选中。
2. 侧栏无设备 / 无匹配：居中小白卡（圆角 + 轻阴影），文案与现引导一致；有可见项时隐藏。
3. 文件卡「打开 / 目录 / 复制路径」与失败「重发 / 重试 / 重发剩余」：位图圆角胶囊（非直角 `<td>`）。
4. `#cancelUploadBtn` / `#clearQueueBtn`：描边胶囊、最小高度约 28px；聊天区与文件 Tab 同样式。
