# 空态白卡层次与输入字号

- 状态：已实现（待手测）
- 背景：未选设备时三步文案已有，但整页灰字扁平；输入区 13px 相对气泡 16px 偏小。
- 目标：空态用居中白卡 + 标题/步骤层次；输入区字号上调；空会话提示略加强。
- 非目标：空态插画；改三步业务含义。

## 用户故事

作为新用户，我打开应用希望空页一眼像现代产品引导，而不是灰字说明书。

## 行为

1. 未选对端：居中白卡，标题加粗，三步条目清晰，「+ 加 IP」主色强调。
2. 搜索无结果：同一白卡风格，文案说明可 Esc 清除。
3. 已选对端但无消息：空会话提示略大、仍居中。
4. 输入框字号约 15px，与气泡更协调。
