# 下载目录与发送文件夹图标分家

- 状态：已实现（待手测）
- 背景：顶栏、会话顶栏、输入栏三处都用 `folder-plus` 金文件夹+号，看起来像同一功能；实际顶栏与会话顶栏都是「打开下载目录」，输入栏是「发送文件夹」。
- 目标：打开下载 ≠ 发送文件夹，一眼可辨；去掉会话顶栏与顶栏重复的下载入口。
- 非目标：改下载路径逻辑；改发送文件夹能力；托盘菜单文案大改。

## 用户故事

作为使用者，我希望：找刚收到的文件时点「打开目录」；要发整夹时点「文件夹」；两套入口不会因图标撞车而点错。

## 行为

1. 顶栏「打开下载目录」改用无加号的文件夹图标（`folder.svg`），tooltip 仍为打开接收目录。
2. 会话顶栏 Tab 旁移除重复的下载目录按钮（全局入口保留顶栏 + 托盘）。
3. 输入工具栏「文件夹」继续用 `folder-plus`，表示发送文件夹。
4. 拖放遮罩等「要发送」语义可继续用 `folder-plus`。
