# 设备行延迟闪电图标与档位色

- 状态：已实现（待手测）
- 背景：列表延迟用旧实心橙闪电，小尺寸发糊且与「极速」语义不符。
- 目标：改用 Lucide zap 实心路径；图标与「Nms」同色；按延迟档变色。
- 非目标：改 Ping 探测周期；改加 IP 探测钮上的旧 `zap.svg`（琥珀描边仍给连通测试用）。

## 行为

1. 小尺寸（13px）用实心 zap 路径绘制，可按颜色染色。
2. 资源：`icons/zap-green.svg`（描边）、`icons/zap-solid.svg`（实心）入库。
3. 档位：`<10ms` → `#059669`；`10~50ms` → `#d97706`；`>50ms` / 分秒级 → `#dc2626`；未知/超时 → `#94a3b8`。

## 验收

- [ ] Z1：在线行闪电为清晰矢量形，非糊像素块。
- [ ] Z2：低延迟为翡翠绿，图标与数字同色。
- [ ] Z3：人为高延迟时变为琥珀/红（可手测或改阈值）。

## 影响范围

- `icons/zap-green.svg`、`icons/zap-solid.svg`、`icons/icons.qrc`
- `src/uiicons.cpp`、`src/mainwindow.cpp`
