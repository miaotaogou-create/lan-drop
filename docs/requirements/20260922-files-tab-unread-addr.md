# 文件 Tab 收声、未读角标与侧栏地址收紧

- 状态：已实现（待手测）
- 背景：文件 Tab 常显「文件 (0)」占视觉；未读红点贴边易糊；侧栏副行 `IP:端口` 在端口与本机相同时冗余。
- 目标：无文件时只写「文件」；未读角标加白描边更清晰；同端口只显示 IP，完整地址进 tooltip。
- 非目标：自定义侧栏 item 控件；改未读计数逻辑。

## 用户故事

作为使用者，我希望：没传过文件时 Tab 更干净；有未读时角标一眼可辨；设备列表副行更短，悬停仍能看全地址。

## 行为

1. 文件数为 0：`文件`；大于 0：`文件 · N`。
2. 侧栏头像未读红角标外圈加约 2px 白描边。
3. 副行地址：端口等于本机传输端口时只显示 IP，否则 `IP:端口`；item tooltip 含完整 `IP:端口` 与其它副行信息。
