# 文件空态键帽、弹窗关闭红悬停与输入脚注

- 状态：已实现
- 背景：文件 Tab 空态无键帽，与聊天空态语言断层；弹窗 ✕ 悬停灰底、主窗关闭钮红底；`#inputHint` 仅有样式无控件，快捷键只藏在 tooltip。
- 目标：文件空态补中文三键帽；弹窗关闭悬停对齐主窗红；输入白卡左下常驻短脚注；发送钮轻阴影。
- 非目标：改快捷键行为；重做弹窗结构；远程桌面。

## 用户故事

作为使用者，我希望切到「文件」也看得出怎么发；关弹窗时悬停手感与关主窗一致；输入区不用悬停也能瞥见发送/换行约定。

## 行为

1. 无文件记录时空态键帽：「附件」「拖入」「文件夹」；脚注保留拖拽/附件说明。
2. 共用对话框 chrome 的 Close:hover 为 `#ef4444`。
3. 输入区左下显示「回车发送 · Shift+回车换行」（Esc/粘贴仍在 tooltip）。
4. 发送 FAB 使用与输入卡同系轻阴影。
