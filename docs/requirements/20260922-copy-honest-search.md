# 设置副标题与搜索空态诚实化

- 状态：已实现（待手测）
- 背景：设置副标题仍写「接收提示」，页内已有抖动/收发通知声/自定义铃声；搜索占位只写名称或 IP，但标签已可搜，筛空时右侧空白无说明。
- 目标：副标题与设置内容对齐；搜索占位提及标签；无匹配时给出可操作提示。
- 非目标：
  - 搜索高亮、拼音模糊
  - 改设置布局结构
  - 真并发线程池

## 用户故事

作为使用者，我希望设置页标题如实概括内容；搜不到设备时能知道该清搜索还是换关键字，而不是一片空白。

## 行为

1. 设置副标题改为概括设备名、下载与通知偏好（含抖动/通知声/铃声），不再写「仅接收」。
2. 左侧搜索占位：名称、IP 或标签。
3. 有搜索关键字且可见对端为 0：右侧空态文案提示无匹配，可清除搜索或按名称/IP/标签再试。
4. 无搜索且无对端：仍用原「还没有对端…」文案。

## 验收标准

- [ ] A1：打开设置，副标题与下方端口/开关/铃声区语义一致。
- [ ] A2：搜索框占位含「标签」。
- [ ] A3：有对端时输入无匹配关键字，右侧出现无匹配说明（非完全空白误解）。
- [ ] A4：清空搜索后列表与空态恢复正常。
