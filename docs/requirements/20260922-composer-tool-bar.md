# Composer 工具行改为分段槽

- 状态：已实现（待手测）
- 背景：会话 Tab 已是灰底分段控件，下方「发送文件 / 文件夹 / 抖动」仍是散落文字链，视觉断层。
- 目标：三按钮收入同一灰底圆角槽，悬停白底浮起，与 `#sessionTabBar` 同语言。
- 非目标：改发送/文件夹/抖动逻辑；收进溢出菜单。

## 用户故事

作为使用者，我希望输入区上方的快捷操作看起来像一组现代工具，而不是三条灰链。

## 行为

1. 三个工具按钮同处 `#composerToolBar` 灰底槽内。
2. 悬停：白底圆角浮起。
3. 点击行为与原先一致。
