# 搜索浮起、meta 对齐、文件送达与状态字色

- 状态：已实现（待手测）
- 背景：侧栏搜索仍平贴灰底，与 hostPill/输入壳浮卡断层；发出 meta 与气泡右缘因阴影错位；文件消息无发送中/已送达徽标；顶栏状态字始终灰，仅圆点变色。
- 目标：搜索浮起白卡；发出 meta 与色块右缘齐；文件 meta 同文字；状态文案随在线/告警变色。
- 非目标：Composer 工具栏并入输入壳；改气泡形状算法。

## 用户故事

作为使用者，我希望：搜设备时输入框也有浮卡感；发出消息的时间戳与气泡齐边；发文件也有送达反馈；顶栏状态扫一眼就懂好坏。

## 行为

1. `#search` 外包 `#searchShell`：白底圆角 + `applyFloatingShadow`；聚焦时蓝边（对齐 inputShell）。
2. 发出/接收消息行：meta 相对位图阴影留白补偿约 5px，与色块边缘对齐。
3. 文件卡 `metaLine` 传 `showSendState=out`（与文字一致）。
4. `setStatusOnline`：正常绿字、告警琥珀字（配合圆点）。
