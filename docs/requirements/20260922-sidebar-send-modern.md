# 侧栏会话列表与发送钮更现代

- 状态：已实现（待手测）
- 背景：侧栏两行纯文本、选中态弱；发送钮浅蓝方角，不像主操作。
- 目标：列表标题/副标题更清、选中更醒目、未读用角标；发送钮圆形主色。
- 非目标：自定义 ItemDelegate 全量重绘；改发现/排序逻辑。

## 用户故事

作为使用者，我打开应用第一眼侧栏就要像现代 IM；发消息时发送钮一眼就是主按钮。

## 行为

1. 侧栏：第一行设备名；第二行 `IP:端口 · 在线/离线`（及手动/置顶等短标签）；未读数画在头像角标，不再塞进标题尾。
2. 选中行：浅蓝底 + 左侧蓝色强调条；悬停略浅。
3. 发送钮：圆形、主色蓝；禁用仍灰。
