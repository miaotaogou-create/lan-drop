# 文件 Tab 空态白卡

- 状态：已实现（待手测）
- 背景：未选对端与聊天空会话已有分层引导，文件传输 Tab 仍是一行灰字，切 Tab 观感断层。
- 目标：无文件记录时居中白卡 + 标题/副文案，与空态体系一致。
- 非目标：改文件列表交互；空态插画资源。

## 用户故事

作为使用者，我点开「文件传输」却还没传过文件时，希望看到清晰引导，而不是空灰字。

## 行为

1. 该对端无文件收发记录：居中圆角白卡，标题「还没有文件传输」，副文案提示可拖到聊天区或点附件发送。
2. 有文件记录时仍为文件卡列表（既有）。
