# 设置打开聚焦设备名；共享中顶栏更醒目

- 状态：已实现（待手测）
- 背景：打开设置后焦点常不在设备名，改名要再点一次；网页共享开启后按钮只改文案「共享中…」，色块仍像未开，扫顶栏不够醒目。
- 目标：设置弹窗打开即聚焦并选中设备名；共享进行中顶栏按钮用绿色系高亮。
- 非目标：改设置项内容；改共享协议。

## 用户故事

作为使用者，我打开设置想改设备名能直接打字；共享开着时顶栏一眼能看出来。

## 行为

1. 打开设置：焦点在「本机设备名称」，文本全选便于覆盖输入。
2. 网页共享有共享目录时：顶栏按钮文案仍为「共享中…」，背景/边框改绿色系（与未共享的蓝底区分）。
3. 停止共享后恢复原蓝底样式与「网页共享 (HTTP)」文案。
