# 上传中非打断提示

- 状态：已实现（待手测）
- 背景：发送中再点「发送文件/文件夹」、拖放或点失败重试时，会弹出模态「请稍候」，打断看进度的视线。
- 目标：改为非模态提示（输入区上方进度文案），不打断当前传输、不弹框。
- 非目标：
  - 发送中自动把新文件加入队列（可后续）
  - 取消当前上传

## 用户故事

作为使用者，我传大文件时误点了发送或拖入了文件，希望轻轻提醒一声就好，不要再点确认框。

## 行为

1. 下列入口在 `m_uploading` 时：不再 `QMessageBox`。
   - 发送文件 / 发送文件夹
   - 聊天区拖放 / 粘贴文件
   - 失败条「重试」
2. 改为调用统一提示：进度区显示「正在发送中，请稍候再添加」（重试可用「请等待当前文件传完后再重试」）。
3. 不中断当前上传；随后上传进度回调会覆盖回百分比文案。
4. 「未选对端」仍可保留信息框（本轮可不改）。

## 验收标准

- [ ] B1：发送中再点发送文件/文件夹，无模态框，进度区有稍候提示。
- [ ] B2：发送中拖入文件，无模态框，有稍候提示，当前传输继续。
- [ ] B3：发送中点失败重试，无模态框，有稍候类提示。
- [ ] B4：传完后可正常再发文件。
