# 上传中非打断提示

- 状态：已实现（待手测；忙时入队见 `20260922-upload-queue-append.md`）
- 背景：发送中再点「发送文件/文件夹」、拖放或点失败重试时，会弹出模态「请稍候」，打断看进度的视线。
- 目标：改为非模态提示（输入区上方进度文案），不打断当前传输、不弹框。
- 非目标：
  - 发送中自动把新文件加入队列（已落地，见 `20260922-upload-queue-append.md`）
  - 取消当前上传

## 用户故事

作为使用者，我传大文件时误点了发送或拖入了文件，希望轻轻提醒一声就好，不要再点确认框。

## 行为

1. 下列入口在 `m_uploading` 时：不再 `QMessageBox`。
   - 发送文件 / 发送文件夹
   - 聊天区拖放 / 粘贴文件
   - 失败条「重试」
2. 成功入队时以系统条提示为主（见入队需求）；仅「已在队列中」等去重场景仍用进度区轻提示。
3. 不中断当前上传；随后上传进度回调会覆盖回百分比文案。
4. 「未选对端」仍可保留信息框（本轮可不改）。

## 验收标准

- [ ] B1：发送中再点发送文件/文件夹，无模态框（成功则入队系统条，见 Q1/Q2）。
- [ ] B2：发送中拖入文件，无模态框，当前传输继续。
- [ ] B3：发送中点失败重试，无模态框。
- [ ] B4：传完后可正常再发文件。
