# 复制成功即时提示

- 状态：已实现（待手测）
- 背景：文字/路径/代码「复制」后无反馈，不确定是否已进剪贴板。
- 目标：聊天内复制类操作成功后，鼠标旁短暂提示「已复制」。
- 非目标：自定义提示样式；改本机/对端地址复制（已有提示）。

## 用户故事

作为使用者，我点复制后希望马上知道成功了。

## 行为

1. `landrop://copy/`（文字气泡、代码块）：成功写入剪贴板后，`QToolTip` 显示「已复制」。
2. `landrop://copypath/`：显示「已复制路径」。
3. 空内容不提示。
4. 本机地址 / 对端地址复制保持现有文案。

## 验收标准

- [ ] F1：点文字气泡「复制」出现「已复制」提示，剪贴板正确。
- [ ] F2：点「复制路径」出现「已复制路径」。
- [ ] F3：代码块「复制」同样有「已复制」提示。
