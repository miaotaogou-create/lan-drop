# 聊天头像与气泡对齐参考图

- 状态：已实现（待手测）
- 背景：对照参考图，当前聊天区字母头像偏小（约 28px 直角），气泡用 HTML table 无有效圆角（Qt 富文本几乎不渲染 `border-radius`），观感成直角块。
- 目标：头像与文字气泡视觉对齐参考图——头像明显更大；气泡为统一圆角矩形（无尖角/尾巴）。
- 非目标：
  - 重做文件卡/代码块交互
  - 换掉 QTextBrowser 消息流架构
  - 侧栏/会话顶栏 SVG 头像体系

## 用户故事

作为使用者，我希望聊天区的头像大小和气泡圆角像参考图一样，一眼对得上设计稿。

## 行为（对照参考图）

1. 字母头像边长约 **44px**（见 `20260922-bubble-shape-scale.md`），圆角方或正圆（与参考图一致的柔和外形），对端橙底、本端蓝底，白字首字母。
2. 文字气泡为**四角统一的圆角矩形**（约 16px 圆角），无尖角/尾巴；字号与留白见 `20260922-bubble-shape-scale.md`。
3. 发出：蓝底白字；收到：白底深字 + 浅灰细边。
4. 头像仍在气泡侧下方对齐；元数据行仍在气泡上方。

## 验收标准

- [ ] B1：聊天区头像明显大于改前，目视接近参考图比例（约 40px）。
- [ ] B2：发出/收到文字气泡均为圆角矩形，非直角块、无尾巴。
- [ ] B3：蓝/白配色与左右对齐不变；切会话历史重绘仍正确。
