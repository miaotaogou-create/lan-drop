# 会话顶栏可打开下载目录

- 状态：已实现（待手测）
- 背景：收完文件后常在会话里；顶栏已有下载目录入口，但视线在会话区时还要抬头找，多一步。
- 目标：会话顶栏（聊天/文件 Tab 旁）增加打开下载目录按钮，复用既有 `openDownloadDir`。
- 非目标：改下载路径；文件 Tab 内再列目录树。

## 用户故事

作为使用者，我在和某台设备传文件时，希望就近打开本机下载目录核对刚收到的文件。

## 行为

1. 会话顶栏 Tab 右侧有「下载目录」按钮（图标+文案或图标+悬停说明）。
2. 点击后打开设置中的接收目录（与顶栏/托盘同一逻辑）。
3. 目录不存在时行为与既有打开下载目录一致。
