# 本机发送文件完成也播通知声

- 状态：已实现（待手测）
- 背景：设置开关文案为「新消息与传输完成通知声」，但目前只在**收到**文字/文件时响；本机发完大文件后无声，与文案不符。
- 目标：开关打开时，本机文件发送成功（气泡变为完成态）也播一次同一套系统提示音；关掉则仍静音。
- 非目标：
  - 本机发出文字成功时的提示音（非「传输」）
  - 发送失败时的提示音
  - 自定义铃声 / 音量
  - 引入 Qt Multimedia

## 用户故事

作为使用者，我希望发出大文件传完时也有一声提醒，好把注意力从别处转回来；也可在设置里关掉。

## 行为

1. 文件上传成功走现有 `finishUploadMsg` 时：若 `soundNotification` 为真，调用与收件相同的 `playNotifySound()`。
2. 发送失败、队列清空、进行中进度刷新：不播。
3. 收到文字/文件、抖动：行为不变（收件播、抖动不额外播）。
4. 保存设置后立即按新开关生效。

## 验收标准

- [ ] S1：通知声开，向对端发文件至完成，本机听到一次提示音。
- [ ] S2：通知声关并保存后，再发文件完成，本机无声。
- [ ] S3：发文字成功不因本需求多播一声。
- [ ] S4：收件提示音与开关行为仍符合 `20260922-sound-notification.md`。
