# 点聊天区聚焦输入与未读更醒目

- 状态：已实现（待手测）
- 背景：从别处点回主窗口后常还要再点输入框才能打字；未读只是名称后「· N」，不够抢眼。
- 目标：在聊天消息区点一下（非必须吃掉链接点击）即可聚焦输入框；列表未读改为更明显文案并加粗设备名。
- 非目标：改未读计数规则；托盘图标角标。

## 用户故事

作为使用者，我希望点一下聊天区就能打字，并一眼看出谁有未读。

## 行为

1. 已选对端时：在聊天 `QTextBrowser` 上按下鼠标左键 → 输入框获得焦点（不拦截锚点/链接原有点击）。
2. 列表未读：文案由 `· N` 改为 ` · 未读 N`；该行设备名使用加粗字体。
3. 未读清零规则不变（见 `20260922-unread-badge.md`）。

## 验收标准

- [x] C3：有未读时列表可见「未读 N」且名称更醒目；点入后消失（实现已对齐，待手测）
