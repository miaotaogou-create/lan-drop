# 会话 Ping、链路与文件传输列表

- 状态：已实现
- 背景：会话顶栏副行仍是「Ping — · 链路 —」，「文件传输」页只有占位文案。参考图副行含时延与网线类型，文件页应能看到已传文件。
- 目标：选中对端后显示实测往返时延和本机当前网卡速率；文件传输页列出与该对端已完成的收发文件，Tab 数字同步。
- 非目标：
  - ICMP 特权 Ping（用对端 `/api/info` 往返代替）
  - 气泡内实时进度条（上传进度仍在进度文字）
  - 跨进程持久化传输历史

## 用户故事

作为使用者，我希望看到连上对端后大概多快、本机走的是什么网卡，并能在「文件传输」里回看这次会话收发过的文件。

## 行为

1. **Ping**：选中对端且会话页打开时，约每 2 秒请求一次 `/api/info`，副行显示 `Ping 0.8ms` 这类往返时间；失败显示 `Ping 超时`。
2. **链路**：取本机当前对外 IPv4 所在网卡的链路速率，文案如 `2.5 GbE 网线`、`千兆 网线`、`百兆 Wi-Fi`；读不到则为 `链路 —`。
3. **文件页**：列出当前对端聊天记录里的收/发文件卡；没有则提示还没有文件。按钮文案 `文件传输 (n)`，`n` 为该对端文件条数。进行中的发送在该页顶部显示与聊天区相同的进度文字。

## 验收标准

- [x] P1：选中在线对端后，副行 Ping 从「—」变为毫秒数或「超时」
- [x] P2：副行链路为本机网卡速率描述，不是固定「链路 —」（读不到速率时允许「链路 —」）
- [x] P3：收或发文件后，「文件传输 (n)」数字增加，页内能看到文件名与大小
- [x] P4：切换对端后，Ping 与文件列表跟随当前对端，不串会话
