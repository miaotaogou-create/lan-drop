# 侧栏状态胶囊与副行收紧

- 状态：已实现
- 背景：设备行副行仍是「IP · 离线 · 手动 · 置顶 · os · tag」点分纯文字，与聊天 meta 徽标、文件 chip 不同语系；信息挤、状态难扫。
- 目标：离线 / 手动 / 置顶改为小色块胶囊；副行先地址再胶囊；os/标签弱化为灰字；行用 itemWidget 与白卡选中同系。
- 非目标：全量 QStyledItemDelegate 重绘；改排序/发现逻辑；改头像未读角标。

## 用户故事

作为使用者，我扫左侧列表时希望一眼看出谁离线、谁是手动加的、谁置顶，而不是读一长串点分文字。

## 行为

1. 副行位图：`IP`（或 `IP:端口`）+「离线」「手动」「置顶」胶囊 + os/标签灰字。
2. 行用 `setItemWidget`；选中仍靠 `#peerList::item` 白卡蓝边。
3. item 文本保留名/地址/标签供搜索。

## 验收标准

- [x] S1：离线设备可见灰底「离线」胶囊
- [x] S2：手动节点可见蓝系「手动」胶囊；置顶可见琥珀「置顶」胶囊
- [x] S3：副行不再用「 · 」串联状态词
- [x] S4：选中行仍为蓝左边线白卡；搜索过滤仍可用
