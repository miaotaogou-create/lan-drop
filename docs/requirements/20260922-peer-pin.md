# 设备列表手动置顶

- 状态：已实现（待手测）
- 背景：在线/未读排序后，常连几台仍会被冲散。
- 目标：右键可置顶/取消置顶，持久化；排序时置顶最上。
- 非目标：拖拽排序、多级置顶权重、发现协议改动。

## 用户故事

作为使用者，我希望把几台常用电脑钉在列表最上，少翻少点。

## 行为

1. 设备列表右键增加「置顶」/「取消置顶」（按当前状态切换文案）。
2. 置顶键写入 settings.json（如 `pinnedPeers`：`ip:port` 列表）。
3. `refreshPeers` 排序：置顶 > 在线 > 未读 > 名称（既有二级键不变）。
4. 置顶设备可带轻微文案标记（如「置顶」），可选。

## 验收标准

- [ ] P1：置顶后刷新/重启仍在列表最上段。
- [ ] P2：取消置顶后恢复按在线/未读排序。
- [ ] P3：settings.json 有 pinnedPeers 并持久。

## 影响范围
