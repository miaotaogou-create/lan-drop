# 输入区快捷键提示改 tooltip，Esc 清空草稿

- 状态：已实现（待手测）
- 背景：工具行常驻「Enter / Shift+Enter」键帽占横向空间，和「发送文件」等抢注意力；草稿想清掉只能全选删。
- 目标：快捷键改到输入框/发送钮悬停提示；输入框按 Esc 一键清空未发送草稿。
- 非目标：改发送/换行快捷键本身；自定义快捷键。

## 用户故事

作为使用者，我希望工具行干净好点文件，快捷键需要时悬停能看到；写错了想一键清掉草稿。

## 行为

1. 去掉工具行常驻键帽条。
2. 输入框与发送钮 tooltip 说明：`Enter 发送，Shift+Enter 换行`（可与原有文案合并）。
3. 输入框有内容且聚焦时按 Esc：清空草稿（不发送）；内容已空则不拦截其它逻辑。
