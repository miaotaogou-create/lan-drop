# 气泡复制可发现性与表单控件对齐

- 状态：已实现（待手测）
- 背景：点气泡可复制已落地，但无悬停提示，能力不易发现；设置「本机展示 IP」下拉仍偏系统原生，与加 IP 弹窗 Combo 不一致；共享弹窗滚动条未跟主窗细条。
- 目标：气泡悬停提示「点击复制」；设置 IP 下拉复用现代表单样式；共享弹窗补细滚动条。
- 非目标：改复制协议；会话内搜聊天记录。

## 用户故事

作为使用者，我悬停文字气泡时希望知道能点复制；打开设置时下拉框不要突然变回「系统味」；共享文件多时滚动条也要细。

## 行为

1. 文字气泡（可点区域）悬停提示「点击复制」。
2. 设置页「本机展示 IP」下拉视觉与加 IP 弹窗 Combo 一致（圆角、箭头、弹出层）。
3. 网页共享弹窗内滚动条为细圆角样式。
