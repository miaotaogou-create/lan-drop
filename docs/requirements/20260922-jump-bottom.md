# 聊天「有新消息 / 回到底部」

- 状态：已实现（待手测）
- 背景：贴底滚动上线后，用户上翻时新消息不会拽视口，但也可能不知道下面已有更新。
- 目标：上翻期间若当前会话又有新内容，聊天区底部出现可点提示；一点滚到最新并隐藏。
- 非目标：
  - 未读条数做进该按钮（列表角标已有）
  - 文件传输 Tab 同等按钮
  - 仅进度百分比变化就刷「有新消息」（避免传大文件时狂闪）

## 用户故事

作为使用者，我希望上翻看历史时，下面来了新消息有个入口能一键回到最新，不用自己狂滚。

## 行为

1. 当前会话可见且不在底部附近时，若发生**新消息入列**（文字收发、文件卡出现/完成、失败条等，不含单纯进度 tick）→ 显示底部居中按钮，文案「有新消息 ↓」。
2. 点击按钮 → 滚到最新并隐藏；清除「下方有新」标记。
3. 用户自己滚回底部附近 → 自动隐藏并清除标记。
4. 切换对端 / `showChat` 强制到底 → 隐藏并清除。
5. 按钮不挡拖放（可点；拖放目标仍是会话页）。

## 验收标准

- [ ] J1：上翻后对端发来文字，出现「有新消息 ↓」；点击后到最新且按钮消失。
- [ ] J2：上翻后自己发文字/文件完成，同样出现并可点回底部。
- [ ] J3：上翻仅看发送进度变化，不因百分比 tick 反复闪出该按钮。
- [ ] J4：手动滚回底部后按钮消失；切换对端后再回来无残留按钮。
