# 离线条暖色、侧栏空态与快捷键提示

- 状态：已实现（待手测）
- 背景：离线连接条仍用绿盾+白胶囊，与琥珀文案冲突；侧栏 0 设备时列表空白且「附近在线」+ 绿色角标略误导；Ctrl+V / 搜索 Esc 可发现性不足；列表拖放遮罩比聊天区单薄。
- 目标：离线条一眼可读为警示；侧栏无设备有轻引导、角标与标题诚实；输入/搜索 tooltip 补齐；列表拖放遮罩与聊天区同级。
- 非目标：自定义 QMessageBox；会话顶栏大改；会话内搜记录。

## 用户故事

作为使用者，我希望：对方离线时顶条颜色语义正确；还没发现设备时左侧也有下一步提示；常用快捷键不用猜；拖到侧栏时反馈和拖到聊天一样清楚。

## 行为

1. 选中离线对端时：连接条浅琥珀底+暖边；图标为警示三角（非绿盾）。
2. 侧栏标题为「附近设备」；可见设备数为 0 时角标灰底；列表区叠轻引导（等待发现 / 点「+ 加 IP」）；有可见项时隐藏引导。
3. 搜索框 tooltip 含 Esc 清除；输入框 tooltip 含 Ctrl+V 粘贴文件/截图。
4. 列表拖放遮罩含图标 + 主文案 + 副文案，风格对齐聊天拖放。
