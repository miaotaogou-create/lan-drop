# 设备列表右键：复制地址与发送文件

- 状态：已实现（待手测）
- 背景：右键已有置顶/清空聊天/编辑手动节点；日常高频「复制 IP:端口」「给这台发文件」仍要先选中再点工具栏，多一步。
- 目标：右键菜单增加这两项，选中该设备后即可操作。
- 非目标：拖拽排序；给发现节点做「编辑」；远程控制。

## 用户故事

作为使用者，我对着列表某台设备右键，希望能直接复制地址或选文件发给它。

## 行为

1. 对任一列表项右键：菜单含「复制 IP:端口」「发送文件…」（在置顶等项附近，顺序清晰）。
2. 「复制 IP:端口」：写入该行 `IP:端口`，短暂「已复制 …」提示（与顶栏复制反馈一致）。
3. 「发送文件…」：选中该对端后打开既有多选文件对话框并入队发送。
4. 原有置顶 / 清空聊天 / 编辑 / 删除手动节点保留。
