# Composer 工具钮悬停、占位与发送禁用态

- 状态：已实现（待手测）；工具图标保持 SVG 原色（静音染色已撤回）
- 背景：一体化输入卡方向正确；中间缺清晰占位；空草稿时发送钮偏亮。曾试过工具图标默认静音灰，观感过素已撤回。
- 目标：占位可见；无字时发送钮明显静音；工具钮悬停有底色反馈，图标保留品牌色。
- 非目标：改发送/文件夹/抖动业务逻辑；重做输入卡结构。

## 行为

1. 文件/文件夹/抖动：图标用 SVG 原色；文字默认 `#64748b`；悬停分别亮蓝/琥珀底与字色。
2. 占位：`向 {名} 发送消息…` 或 `输入消息…（Enter 发送，Shift+Enter 换行）`；色 `#94a3b8`。
3. 发送钮：无草稿 `#bfdbfe`；有字 `#2563eb`。

## 验收

- [ ] C1：三工具钮图标可见品牌色，非灰死。
- [ ] C2：有对端时输入区可见占位文案。
- [ ] C3：空输入时发送钮明显淡于有字态，且不可点。

- `src/uiicons.{h,cpp}`、`src/mainwindow.cpp`
