# Composer 工具钮静音、占位与发送禁用态

- 状态：已实现（待手测）
- 背景：一体化输入卡方向正确，但工具三钮默认七彩、中间缺清晰占位锚点、空草稿时发送钮仍偏亮。
- 目标：工具钮默认静音灰、悬停亮色；占位可见且含快捷提示；无字时发送钮明显静音。
- 非目标：改发送/文件夹/抖动业务逻辑；重做输入卡结构。

## 行为

1. 文件/文件夹/抖动：默认图标+文字 `#64748b`；悬停分别蓝 / 琥珀 / 深琥珀底与字色。
2. 占位：`向 {名} 发送消息…` 或 `输入消息…（Enter 发送，Shift+Enter 换行）`；色 `#94a3b8`（palette，不被 QSS color 盖掉）。
3. 发送钮：无草稿 `#bfdbfe`；有字 `#2563eb`；禁用箭头光标不变。

## 验收

- [ ] C1：三工具钮默认同为静音灰，悬停才亮对应色。
- [ ] C2：有对端时输入区可见占位文案。
- [ ] C3：空输入时发送钮明显淡于有字态，且不可点。

## 影响范围

- `src/uiicons.{h,cpp}`、`src/mainwindow.cpp`
