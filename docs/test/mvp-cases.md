# MVP 验收用例

对应需求：`docs/requirements/20260320-局域快传-mvp.md`

### TC-01 文本收发与中文
- 对应验收：A3
- 前置：本机 HTTP 服务已启动
- 步骤：向 `/api/inbox` 投递 UTF-8 中文，再 `GET /api/messages`
- 期望：会话中能读回原文
- 类型：单元
- 自动化：`internal/server/server_test.go` `TestInboxAndMessages`

### TC-02 文件流式落盘且不逃出目录
- 对应验收：A4
- 前置：临时下载目录
- 步骤：以 `../` 文件名调用保存；再保存同名第二份
- 期望：文件留在下载目录；同名不覆盖
- 类型：单元
- 自动化：`TestUploadSavesBytes`、`TestRejectsPathEscape`

### TC-03 设置持久化
- 对应验收：A5
- 前置：临时配置文件
- 步骤：修改设备名与下载目录后重新读取
- 期望：值被写回
- 类型：单元
- 自动化：`internal/config/config_test.go`

### TC-04 发现心跳与虚拟网卡过滤
- 对应验收：A1（协议侧，不含双机现场）
- 前置：无
- 步骤：解析心跳 JSON；用虚拟网卡名称过滤
- 期望：能还原节点；VMware/WSL 等被排除
- 类型：单元
- 自动化：`internal/discover`

### TC-05 手动加节点与探测
- 对应验收：A2
- 前置：两台进程或对端 `/api/info` 可访问
- 步骤：界面「+ 加 IP」，填写 IP 与 8848，点测试连通，再添加
- 期望：探测成功后列表出现该节点
- 类型：手测

### TC-06 同网段自动发现
- 对应验收：A1
- 前置：两台 Windows 或 Win+ARM 麒麟，同网段，放行 TCP 8848 与 UDP 8850
- 步骤：两边运行程序，打开页面等待约 60 秒
- 期望：设备列表出现对端名称或 IP
- 类型：手测

### TC-07 大文件
- 对应验收：A4
- 前置：同 TC-06
- 步骤：发送一个不小于 100MB 的文件
- 期望：接收目录出现完整文件；发送过程内存不随文件体积线性涨满
- 类型：手测

### 缺口
- 文件夹发送：需求故事有，本阶段未实现（见架构说明已知限制）
- HTTP 网页共享扫码提货：界面标明后续版本
- A1/A4/A6 的双机与交叉编译产物需在目标机手测；仓库提供构建命令
