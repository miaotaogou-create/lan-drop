# MVP 验收用例

对应需求：`docs/requirements/20260320-局域快传-mvp.md`  
当前交付物是 Qt 客户端，不是 Go 里那套网页接口。下面标的是 2026-09-21 在本机对 Qt 包的执行结果。

### TC-01 文本收发与中文
- 对应验收：A3
- 前置：Windows 包 `dist/windows-x64/landrop.exe` 已启动
- 步骤：向 `POST /api/inbox` 投递 UTF-8 中文
- 期望：接口返回成功，对端聊天区能看到 UTF-8 中文
- 类型：集成
- 自动化：`powershell -File tests\api-smoke.ps1`
- 结果：通过。2026-09-21 Windows（omen / 10.100.20.223）向麒麟（qwer-pc / 10.100.20.22）投递「双机验收 dual-110527」，麒麟聊天区可见。反向「麒麟回传 110548」出现在 Windows 聊天区

### TC-02 文件落盘、中文名、不逃出目录、同名不覆盖
- 对应验收：A4 的落盘部分
- 前置：临时工作目录
- 步骤：上传 `说明.txt`；再以 `../../outside.txt` 上传；再传一次同名
- 期望：文件在下载目录内，中文名保留，穿越被收成基本名，同名不覆盖
- 类型：集成
- 自动化：`tests\api-smoke.ps1`；另有 `--self-check` 覆盖文件名裁剪和网卡过滤
- 结果：通过

### TC-03 设置能被读到
- 对应验收：A5
- 前置：已有 `%AppData%\lan-drop\settings.json`，设备名 omen
- 步骤：启动后看 `GET /api/info`
- 期望：返回的名称是配置里的设备名
- 类型：集成
- 结果：通过（返回 `omen`）。改设置后再读回、以及界面保存，本轮没做

### TC-04 自检：路径、虚拟网卡、广播地址
- 对应验收：A1 的协议辅助，不是双机发现
- 步骤：`landrop.exe --self-check`；ARM 包在交叉编译脚本里用 qemu 跑同一自检
- 期望：退出码 0
- 类型：单元
- 结果：Windows 通过。ARM 包在打包时自检通过。注意：无控制台的 exe 不能用 PowerShell 的 `$LASTEXITCODE` 判断，必须看进程退出码

### TC-05 手动加节点与探测
- 对应验收：A2
- 类型：手测
- 结果：未测。只确认了探测会用到的 `GET /api/info` 能返回。界面上的「添加节点」「探测」没点

### TC-06 同网段自动发现
- 对应验收：A1
- 前置：两台机器，放行 TCP 8848 与 UDP 8850
- 步骤：两边运行，等约 60 秒
- 期望：设备列表出现对端
- 类型：手测
- 结果：通过。2026-09-21 两边列表都是 1 台在线：Windows 看到 qwer-pc 10.100.20.22:8848，麒麟看到 omen 10.100.20.223:8848。文字与小文件双向都落到了对端聊天区和下载目录（Windows `downloads/from-kylin-now.txt`，麒麟 `~/landrop/downloads/from-windows.txt`）

### TC-07 大文件
- 对应验收：A4
- 步骤：本机向自己的 `POST /api/upload` 送 100MB
- 期望：落下的文件长度为 100MB；进程工作集不按文件大小上涨
- 类型：集成（只覆盖接收落盘，不覆盖窗口里点「发送文件」，也不是两台机器）
- 结果：通过。文件 100MB，工作集大约增加 0.4MB

### TC-08 网页共享列表与下载
- 对应验收：A9
- 前置：用环境变量 `LANDROP_SHARE_DIR` 指向含 `hello-share.txt` 的目录启动
- 步骤：`GET /share/`；再下载 `/share/hello-share.txt`
- 期望：列表含该文件名；下载内容正确
- 类型：集成
- 自动化：`tests\api-smoke.ps1`
- 结果：通过（`tests\api-smoke.ps1`，2026-09-21）

### 缺口
- 文件夹发送：需求故事有，本阶段未实现
- 扫码：A9 只提供链接复制，未做二维码
- 窗口里点「发送文件」没点过；双机小文件走的是同一套 `/api/upload`，两边聊天区都出现了收到记录
- 发送失败会写进会话；发文件时输入栏上方有百分比。这两项本轮只核对了代码，没有故意制造失败或对着大文件看进度
- 仓库里的 Go 测试（`go test ./...`）测的是旧 Go 进程，不能代替 Qt 客户端
